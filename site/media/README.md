## Actual native WebView built-in FX editor modules

The following are captures of the original approved editor HTML, CSS and JS
from the native WebView2 resource bundle generated by
`scripts/build_approved_native_gui.py`, using
`scripts/capture_public_fx_gallery.py`:

- `fx-editor-8d-sonku.jpg` — 8D-SonKu
- `fx-editor-vocal-delay.jpg` — Vocal Delay
- `fx-editor-harmonice.jpg` — Harmonice (full panel after accepted control test readback)
- `fx-editor-channel-eq.jpg` — Parametric EQ
- `fx-editor-compressor.jpg` — Compressor
- `fx-editor-graphic-eq31.jpg` — Graphic EQ 31

`fx-gallery-provenance.json` records the exact source commit, source GUI
bundle SHA-256 and per-image catalog ID, checksum and capture method.
The controlled browser bridge simulates **only** native state transport to
render each original editor. The screenshots show UI, not Windows HWND
execution, audio DSP/ASIO performance or independent installer qualification.

ImmerSIB and Guitar FX are JUCE-drawn editors and still need authentic native
Windows screenshots. [Issue #867](https://github.com/masarray/arsonmix/issues/867)
tracks those specific remaining captures and release comparison. Do not
substitute a rejected pedal concept, stock asset, second mixer GUI or mocked
JUCE editor for a native screenshot.

Capture again when native editor UI changes and verify the approved GUI build,
actual pixels, asset checksum, responsive site and README links before publishing.

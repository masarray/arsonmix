# Approved ArSonMix marketing screenshots

The JPEGs in this folder were captured with `scripts/capture_landing_screenshots.py` from the **single approved, generated** `dist-pages/preview/index.html`, including the accepted PNG hardware keys. These are authentic Chromium GUI captures, not a substitute for Windows native hardware verification.

- `console-overview.jpg` — full 1680 × 900 console.
- `console-routing.jpg` — 1060 × 355 WIRE and FX rack controls in the approved console.
- `console-faders.jpg` — 1060 × 355 meters, buttons and channel faders.

The landing and README may reuse these images. **Never label a screenshot of the browser FX rack as a native effect editor.** The current gallery does not yet include dedicated Windows captures of the ImmerSIB, Harmonice, Vocal Delay, Guitar FX and other native editor windows.

## Native FX screenshot acceptance for a later visual milestone

Capture dedicated native editor screenshots only from an actual qualified Windows build, with version/SHA provenance, a readable unclipped window, no simulated GUI and no personal paths or credentials. Add them under `site/media/` with descriptive names and honest captions; verify screenshot accuracy against the shipped editor. Do not revive rejected `/preview-v2/`, obsolete v0.3 visuals or a second console.

On future GUI updates, re-run the screenshot script on the newly compiled approved `/preview/` and check desktop/mobile landing smoke tests before publishing.

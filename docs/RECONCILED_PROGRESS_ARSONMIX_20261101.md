## Product contract

Windows-first, low-latency, **LIVE PERFORMANCE** native digital mixer and VST3 host for stage, karaoke, podcast and broadcast. Studio One/Fender Studio Pro **Console**, not its DAW timeline/editor. Source, audio interface and physical/virtual output are **operator-selectable**; OBS or VB-Cable is NOT required. One JUCE callback, one accepted active mixer graph; avoid RT allocations/locks/device reopens, VST instance lifecycle in audio callback, JS DSP, false visual meters, automatic unsafe ARM, or literal "zero milliseconds" claims. Compact premium GUI must remain responsive on modest iGPU hardware.

## P0 hardware truth — BEFORE a release claim

On the supplied user screenshots, CH07 stereo IN1/2 was `LIVE · ACK` while AUDIO SETUP/SIGNAL CHECK showed `OUTPUT SAFE-MUTED`. The sound heard in that state was **not established as processed by ArSonMix MAIN**. Earlier [#15 field evidence](https://github.com/masarray/arsonmix/issues/15) separately showed a routed/ARMED 48 kHz / 480-frame 0FX `VB-Cable CABLE Output capture → MAONO headphone render` with 113 WASAPI *capture discontinuity* flags across 8,126 callbacks, while DSP peak 375 μs / 10,000 μs and over-budget callbacks=0. #259 cites another user 0FX report with 23 flags over 11,744 callbacks. These flags are **NOT proven renderer starvation** and the traces alone do not prove clock drift or DSP overload.

Controlled physical FAT, not CI:
- Use safe headphone volume, no VST3, actual native *readback* of device endpoints and source/output pins; **MUTE / APPLY / native ACK / ARM** as required by the *actual merged* build.
- Confirm source → CH07 (or verified CH) → post-fader meter → MAIN PCM → MAONO hardware. Pull CH fader to −∞, MUTE CH, then MUTE MASTER; **audible sound must follow**. If sound persists, isolate MAONO direct monitoring, Windows Listen or another player/output route. Avoid feedback loops.
- A/B **same-interface MAONO full-duplex ASIO** versus **VB-Cable capture → MAONO Windows Audio** and isolated OUTPUT ONLY / CAPTURE ONLY / DRY THROUGH, matched rates and wired output. Mark crackle events and COPY FULL REPORT, distinguish capture flags from callbacks and render xruns.
- Require **≥30 minutes clean 0FX** on the intended supported wired path, followed by 1FX and multiFX, safe device restart/epoch, channel pan/fader, physical input/output switch, and audible bus routing, before calling this product reliable.

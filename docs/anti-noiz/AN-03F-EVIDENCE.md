## Executable offline tool
Build standalone as usual. Run anti_noiz_qualify with three local, appropriately licensed and format-matched WAV files:
- clean.wav: desired audio only (recorded speech/singing/music).
- noise.wav: noise-only test stem, exactly same timeline/length as clean, no automatic resampling or normalization.
- learn.wav: independent noise-only capture/segment, >2 s, same rate/channel layout; do not reuse the test noise.
- segments.tsv: whitespace-separated label, start frame (inclusive), end frame (exclusive), active or idle; label meaningful weak consonants, onsets, tails, sustained notes, mixed passages and true idle separately. A stereo active label reports aggregate and each non-silent desired channel. Idle labels require near-zero desired reference.
- provenance.tsv: three tab-separated fields per line: role (clean/noise/learn), license identifier, source/creator/credit. Include original source URL/revision, any conversion and permission notes in the source field or local supplementary manifest; record source WAV SHA-256 and executable/source revision in the experiment log. This is human-reviewed metadata, not automatic license verification. Do not commit corpus WAVs or rendered derivatives.

Example (one local case):
    anti_noiz_qualify clean.wav noise.wav learn.wav segments.tsv provenance.tsv ./case-auto14 auto 14 1 > case-auto14.csv

Use a unique output prefix per mode/Clean/Protect and retain unchanged stems and labels across comparisons. Silence is always zero to isolate active spectral performance. Outputs are aligned raw input, processed, Noise Delta and clean-only render with the same learned profile/settings. No automatic level normalization, no clipping accepted in input mix. Prepare/resample externally with documented conversion; preserve stereo, avoid repeating identical learn and test PCM. Existing renderer uses an independent core instance per render; clean-only output quantifies distortion in the absence of added noise, not the exact desired component of a nonlinear mixed render.

CSV contains active clean-reference error improvement (residual noise plus desired distortion), desired projection, removed projection (can include correlation with added noise), clean-only error relative to clean energy, and true-idle attenuation. Projection near one is not a perceptual pass; do not interpret active error as isolated noise attenuation. Numerical log floor is 1e-24 in summed energy. Negative error improvement is a regression. An empty metric is not zero. Channel -1 is all channels. Preserve raw Noise Delta for listening; do not normalize it independently when comparing suppression depth. No universal pass thresholds for real corpus until source coverage and listening establish meaningful criteria. Existing synthetic gates remain unchanged.

## Reproducibility and coverage
Run current and exact baseline revision on identical input and compare per-segment metrics. For baseline prior to this executable, build the qualification source against that revision's compatible OfflineAudio/Core API in a separate worktree; record both source identities. Match reduction and perform blind/level-controlled listening: separately rate foreground quality, residual noise and overall quality (ITU-T P.835 for speech, https://www.itu.int/rec/T-REC-P.835 ; musical listening protocol must additionally cover tone/tails/stereo). Use clean reference, noisy reference, processed and delta.
Candidate sources: VocalSet (https://zenodo.org/records/1203819, CC BY 4.0; check individual metadata), MUSAN (https://openslr.org/17, check per-clip terms and note 16 kHz bandwidth limits), and own licensed full-band microphone/interface recordings. Narrowband resampled speech is not evidence of full-band air preservation. Collect real male/female speech, whisper, fricatives, singing/vibrato/falsetto, tails, acoustic instruments, stereo/dense music, voice over backing, and independent fan/AC/hum/hiss/nonstationary noise. Keep audio outside Git and normal PR CI. No claim of licensing or real corpus qualification until clips and rights are verified.

CTest adds synthetic qualification self-test: exact known 6.0206 dB metric, channel/foreground loss, invalid range, actual Core aligned unity and active Voice path. This is not a real corpus test or new active benefit gate; prior mandatory regression gates remain unchanged. Local full DSP compile and corpus/listening results must be reported separately; no Windows dispatch or native admission.

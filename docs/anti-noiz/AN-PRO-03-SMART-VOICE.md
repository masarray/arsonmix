# AN-PRO-03 — Sidechain Detector & Smart Voice

Opt-in Smart Voice extends the existing linked peak detector, not the old auto residual or a classifier. User threshold remains the lower bound, learned sidechain peak + margin is the candidate, and adjustable maximum lift (0–24 dB) limits it. Effective threshold <= 0 dBFS. Margin 3–18 dB, defaults 9 dB and 12 dB max lift. Manual mode is unchanged; zero lift is equivalent to manual threshold. Ratio, Range, Attack, Hold, Release and Knee remain user-owned. Smart does not promise separation of overlapping foreground/noise or force-open low-confidence vocal.

During Learn, measure the same HPF/LPF-linked peak detector at approximately 1 kHz using a fixed 53-bin (3 dB) histogram. Commit histogram windows only at the spectral Learn accepted checkpoint; use the 95th percentile upper edge of accepted samples. Initial overlapping warm-up samples are included in the first sidechain window (bounded by the first checkpoint). Rejected/cancelled Learn preserves old reference; successful Learn replaces it, filter changes invalidate it immediately, clear profile/prepare clears it. No matching reference falls back to manual threshold; no live auto drift. The effective threshold and reference peak are measured telemetry, not durable preset data. New v4 104-byte state and 24-field JSON, v1/v2/v3 migration. No new FFT, dynamic memory, or delay; histogram work only during Learn. Existing hard gates remain.

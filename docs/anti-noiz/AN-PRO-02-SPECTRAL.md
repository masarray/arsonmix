# AN-PRO-02 — manual spectral control

Implements fixed learned anchor, independent reduction (0–40 dB), threshold offset (±20 dB), positive-only adjacent-bin smoothing and slower mask closing (Artifact Control), and evidence-weighted restoration (Vocal Protection). These are original bounded heuristics, not RX algorithms or a vocal classifier. Manual spectral does not use the legacy independent tonal canceller, to keep Reduction and Noise Only coherent. Automatic policy is preserved by default. Spectral on/off independent of expander; explicit reset clears learned PSD and tonal anchor without resetting latency timeline. v3 92-byte state reads v1/v2; 5/18/21 field JSON migration. Manual v2 algorithm changes deliberately to a more predictable fixed-profile response. No learned profile or audition stored.

Audition is an explicit transient live command, not a preset flag. It requires manual spectral, trusted profile, nonzero reduction and either manual expander or automatic Silence 0. It outputs latency-aligned dry minus spectral wet, excludes manual expander, ramps 5 ms, auto expires after two seconds of processed audio, cancels on edits/Learn/reset/bypass. It replaces the channel output including audience feeds: soundcheck only, not monitor-only. No extra FFT or audio latency. Reset/audition use existing fenced ACK queue, rejected when rack bypassed or logical offline. Existing hard wind gates unchanged. Tests cover transfer monotonicity, complement, expiry, reset, migration. Prior exact CI 25/26 GCC and ASan (existing wind proxy only), UI checkbox assertion fixed to wait for ACK, standard corpus pass. Actual final CI/Windows/listening pending.

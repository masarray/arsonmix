# AN-03E — selective Auto for unknown/mixed sources
Parent 0f1e2df20147c31d4b2fbbf69f0c5f38cabc7be2, main 2253001926e6ef318eb00c9673417dc1177df4d6. Prior focused DSP/Web CI 45556738045 and fast native CI 45556737860 PASS.
## Design
Unknown/Mixed Auto previously returned unity for active foreground. New bounded heuristic uses existing ContextGuard temporal PSD (45 ms, capped at 8x immutable anchor), total energy ratio max across channels, three-bin temporal neighborhood ratio, instantaneous per-bin posterior evidence and existing fast-open/slow-close mask. Weak foreground (total ratio <=4) retains prior unity policy; selective authority ramps linearly to full at ratio 12. Cap active attenuation to min(Clean, 12-4*MusicProtect) dB (default 8 dB). High temporal ratio >=2.6 or instantaneous >=7 protects bin at unity; smoothing cannot lower its target. This is a heuristic inspired by subband signal-presence estimation (Cohen/Berdugo, Speech enhancement for non-stationary noise environments, Signal Processing 2001 https://cris.technion.ac.il/en/publications/speech-enhancement-for-non-stationary-noise-environments-2/), not OM-LSA, calibrated probability or a speech/music classifier. Strong total energy is not proof of speech. Voice, Singing and Music policies unchanged in principle; existing stereo link, idle hold, profile anchor/rollback, rate-dependent latency and unity fast path when no suppression remain. No extra FFT stage or lookahead, but unknown/mixed active frames now use the existing inverse FFT and more per-bin arithmetic; previous Auto timing benchmark no longer qualifies this path. No new allocations/locks in source; instrumentation and physical RT still pending. No shared mixer, GUI, global workflow or root CMake change.

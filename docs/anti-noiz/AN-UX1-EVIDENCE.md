# AN-UX1 — feature-isolated native control and Web UX
Owner approved the compact dark/mint GUI and feature-isolated modular monolith. One ArSonMix built-in FX, one C++ DSP source and one web editor; no new repo or alternate public mixer. Native integration intentionally remains unregistered.
## Research applied
- Microsoft WebView2 security: https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security — existing host must validate origin and message schemas; never accept arbitrary event names or commands.
- Microsoft WebView2 performance: https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/performance — batch bounded telemetry rather than per-sample JS calls.
- JUCE APVTS copy/replace state is not realtime-safe: https://docs.juce.com/master/classjuce_1_1AudioProcessorValueTreeState.html — native adapter must serialize off callback, use bounded SPSC for settings and ACK.
- W3C keyboard: https://www.w3.org/WAI/ARIA/apg/patterns/slider/ — native range inputs for pointer and keyboard; visual dial is decorative.
## Implemented
Core adds bounded Music Protect (only adjusts Singing cap from 12 to 6 dB; not music classifier), enabled flag with aligned unity path, and audio-owned gain readback. Disabling or choosing explicit Music cancels in-progress learn; trusted profile remains. Existing AutoProtect remains conservative, not automatic speech identification.
Control reuses existing FxSpsc; command/completion capacity 16, telemetry capacity 2, at most one command per consume, approximately 20 Hz or less telemetry, drop rather than block if full. ACK means settings accepted by DSP, not final output settled. Gain readbacks are min spectral mask and residual frame gain, not broadband measured RMS. No GUI access to audio state. Graph lease and instance identity must be enforced by existing host. No live native state restore, native picker, or WebView2 adapter yet. Core enable is internal latency-aligned unity, not a replacement for existing mixer rack power/bypass ownership; adapter must map to actual rack state and avoid duplicate bypass authorities.
The editor has three compact controls (Clean/Silence dB, Music Protect %), source-mode buttons, Learn and Power, keyboard-accessible native sliders, accepted-state readback. The development transport is deliberately isolated in tools/anti-noiz/web. It mocks settings ACK and rejects Learn; no audio or fake detection. Spectrum blank until real telemetry. Transport contract still needs graph epoch/session and revision validation, ACK timeout/disconnect/reconnect handling, Learn progress, reduction and real spectrum UI. The native owner must implement these before admission. No production bridge is installed.

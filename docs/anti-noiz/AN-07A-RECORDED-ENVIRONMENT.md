# AN-07A — real recorded environment baseline
This qualification-only branch is stacked on exact reconciled AN-06C a44df9b4cc894b7112c08222dcd847a91f7c3957 so the native application build can finish without mutating its source. No production DSP, GUI or graph change. Use existing Core offline renderer and retain legacy Silence=0 CLI default. Explicit Silence=32 lets idle attenuation be measured separately from active suppression.

Recorded CC0 AC (TimBahrij, Freesound 234918) and rain (barkenov, Freesound 640655), from published Leminno processed PCM release assets with pinned size/SHA-256; see https://github.com/Leminno-org/ambient-sounds-library/blob/main/manifest.json. Original field recordings are preprocessed (DC removal/splicing/peak normalization), not raw microphone recordings. Three previously pinned CC0 Bart Massey clean clips. Learn [1,4)s; test starts 8s; nonoverlapping source excerpts, shared scaling at nominal 0 and 10 dB active clip SNR. Mono uses recorded left, stereo preserves channels. 48k conversion uses deterministic linear interpolation for 44.1k foreground. 12 cases × 5 policies; clean0 and Music transparency are hard numerical checks. Active and idle metrics separated; low-energy proxy is not phonetic annotation. Voice active 10dB, idle 25dB, desired projection 0.97–1.03 are report-only target flags for initial baseline; no gate relaxation to prior synthetic/recorded hiss suite. Every render failure logged; any failure makes the run fail. No audio uploaded/committed; JSON and provenance only. No listening or product qualification claimed; target violations must guide AN-07B, not be hidden. More recorded mic/interface hiss, fricatives, music/transient/tail cases, stereo image, subjective matched-level listening and real ASIO remain required.

## AN-07B experimental candidate, predeclared policy
Exact diagnostic run 45600881720: AC first violation frame 11 at ~12.8x, 41 high/172 low FFT frames per clip, 0/39 violating 50ms windows (window ratio ~0.122–3.062); rain first frame 124 at ~7.11x, 17 high/0 low FFT frames, 3 high windows (~0.341–13.786 range). Thus reject-on-any-FFT-frame is unsuitable for recorded colored noise. Candidate uses 50ms energy windows, existing 4x/0.1x bounds, rolls back whole outlier window from PSD/count, requires >=85% of 2s observation, hard-rejects >32x sustained window (conservative heuristic, not validated speech classifier), retains immediate veto for learned highly asymmetric quiet stereo leg. Fixed checkpoint and no allocation; normal accepted accumulation order unchanged. Anchor unchanged on rejection. Synthetic tests add periodic FFT excursions, exclusion of isolated high windows, persistent/excessive contamination, extreme veto; existing prior tests retained. Experimental #902 only; real corpus + prior objective gates + numerical/performance qualification + real speech contamination/listening required before integration. No changes to #900 or global staging.

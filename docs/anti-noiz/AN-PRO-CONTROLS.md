# Anti Noiz professional manual controls — AN-PRO first implementation

Owner direction: pause suppression first, user tuning over universal automatic wind removal. Existing P0 gates remain binding and research candidates remain isolated. Manual mode is opt-in; v1 state and JSON migrate to legacy behavior. No new audio thread or algorithmic delay. Manual gate uses raw-input, stereo-linked peak sidechain HP/LP, 8 ms detector decay, 3 dB gate hysteresis, existing PDC for opening lookahead and added hold compensation equal to that PDC. Attack/release are full-scale linear gain slew times; hold begins after detector drops below threshold. Hard mute at Gate + Range 96; finite range elsewhere. Manual expander works without a profile, bypassed during Learn and Music. Range 0 bypasses manual residual. Spectral Manual independently removes automatic musical floor caps and uses threshold offset on estimator evidence; positive offset increases assumed noise, not the learned anchor. Clean 0 bypasses spectral processing; Clean up to 40 dB; automatic policies still retain their caps. Automatic Silence remains available and is not active when manual selected. Tone removal may contribute independent cut. Legacy P0 hard gates intentionally unchanged.

GUI uses existing ACK/coalescing, collapsed compact advanced controls, measured residual GR (96 dB scale) and detector dBFS. No fabricated live meter. Local standalone header GCC/Clang sanitizer tests passed 8 configurations; integrated tests run in CI.

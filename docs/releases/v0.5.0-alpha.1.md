# ArSonMix v0.5.0-alpha.1 — Windows Alpha Preview

**Public testing release — not a stable or live-production build.**

This is the first user-testable Windows x64 preview of **ArSonMix**, a native JUCE audio mixer with the canonical `/preview/` interface.

## What's included
- Native multi-channel mixer with physical audio I/O selection, channel fader/pan/mute/solo, bus/MAIN routing and WIRE connections.
- **Add Audio Track** from the mixer toolbar; new tracks start without hardware input until one is selected.
- Better automatic MAIN startup and mixer state retention across verified audio-device changes.
- Native built-in channel parametric EQ. The mixer is functional **without any external VST3**.
- Optional first-party FactoryFX packaging infrastructure and VST3 hosting. The factory release lock is **currently empty**: ArSonEQ, ArSonComp, ArSonVerb and ArSonKuPik **are not bundled in this alpha**. Users may add compatible external VST3 with the existing supported workflow.
- Windows x64 Inno Setup installer and portable ZIP built from the **same exact source commit**.

## Choose your download
- **Windows-x64-Setup.exe**: ordinary install / upgrade (recommended for testers).
- **Windows-x64-Portable.zip**: extract to a writable directory, run the included native Windows executable.
- `SHA256SUMS.txt`: verify exact installer and ZIP bytes.
- `BUILD_PROVENANCE.json`, `INSTALLER_PROVENANCE.json`, `FACTORYFX_STAGE_REPORT.json`: inspect tested build identity and optional plugin contents.

## First test
1. Use **Windows 10/11 x64** with an audio interface and compatible driver. For ASIO monitoring, choose the interface's ASIO driver in Audio I/O.
2. Add/select a mixer audio track, assign a real hardware input, check the channel meter and listen to MAIN output. Check fader, mute/solo, channel EQ, stereo/mono switching and WIRE routing.
3. Test changing audio devices and restarting the app; confirm channels, plugin states and project data persist as expected.
4. Report the source commit from `BUILD_PROVENANCE.json`, audio device/driver, buffer size, steps to reproduce, and what you actually heard.

## Known limitations and safety
- **Alpha only:** automated Windows compile/CTest, package hash checks and installer install/upgrade/uninstall testing are engineering evidence, **not proof of audible physical ASIO performance**.
- Physical hardware tests for glitches, low-latency ASIO, BUS processing and some vendor VST3 plug-ins remain pending. **Do not rely on this build for a critical live performance**.
- Optional FactoryFX releases require independent licensing, integrity and JUCE host qualification. No license or activation is bypassed.
- Please back up valuable Shows and presets before trying a development build. Normal upgrades are designed to preserve Studio data, but this remains test software.

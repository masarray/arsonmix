# ArSonMix v0.5.0-alpha.7 — New Digital Mixer Public Preview

**November 10, 2026 — Windows x64 first.** This alpha is a substantial feature and reliability upgrade from the published v0.5.0-alpha.5. It remains a public *preview*, not a claim that all audio interfaces and plugin combinations have been certified. The product owner reports real-world use of the current features as suitable for wider public trial.

## New and improved
- **Real native digital mixer:** approved /preview/ mixer GUI in JUCE/WebView2, one ChannelId PCM routing graph, hardware inputs on mixer channels, source-only workflow, WIRE routing, physical MAIN/BUS path, fader, mute, solo, FX racks and VST3 host.
- **ArSon Player:** native music playback, independent KEY and TEMPO processing, per-song stage controls, folder import and safe missing-media relinking, without pulling filesystem work into realtime audio.
- **Singer FX:** built-in ArSon Harmony with phase-safe processing, improved warm/clickless bypass and bounded musical-key retargeting; ArSon Vocal Throw performance-delay FX with manual/auto tempo, phrase and beat-aware timing; familiar built-in parametric EQ and low-latency compressor.
- **Sessions and hardware:** retained mixer/.smix workflow, first-launch SOURCE NONE support, ASIO4ALL/input reconnect and restart recovery work; output-only FX workspace when no capture device is available.
- **Desktop polish:** native continuous ArSonMiX titlebar, clearer version/copyright and responsive window buttons; WIRE connector layout tracks window resizing; user-facing audio status no longer displays internal development/FAT metadata.
- **Safer Windows updates:** integrated on-exit Smart Auto Updater M3 for verified, installed Inno builds, with bounded staging, user data preservation and repair/rollback guards. It does not force-close an active mixer. Existing alpha.5 users must run this installer once to bootstrap automatic updates.

## Installation
Download the **Windows x64 Setup** from this prerelease. Close any live performance before manually upgrading. Inno Setup preserves Studio and saved .smix files. Portable packages are for separate manual usage and do not install the auto-update supervisor. The optional first-party VST3 bundles are included only when reported in FACTORYFX_STAGE_REPORT.json; do not assume all sibling plugins ship by default.

## Boundaries
Actual USB/ASIO interface, sample rate, plugins, WASAPI/OBS copy, exclusive device ownership and no-crackle behaviour depend on hardware; there is no blanket zero-xrun certification. Automatically updating a running audio session is intentionally prohibited. The Windows installer is not asserted to be Authenticode-signed. Linux/macOS assets are published only if separately qualified from this exact source. If a specific setup fails, retain the previous working version and report the interface/driver, rate, buffer and reproduction details.

**Source integrity and release status:** release source is an exact immutable SHA, independently built and tested by Windows CTest, approved GUI, native packaging, Inno upgrade/uninstall, and SHA256/provenance gates before publication. Publishing is forbidden if those gates fail.

## What changed

- **Built-in FX workflow:** EQ, Compressor, Harmonice and Vocal Throw can use user presets in a logical/offline workspace without requiring an active audio device. FX Picker now waits for accepted native graph identity/readback, then closes the picker and opens the selected editor. Failed insertion does not fake a successful FX editor.
- **Predictable controls and floating tools:** consistent compact Close buttons, centered and draggable utility windows, outside-click dismissal for temporary tools, visible plugin-editor controls, responsive layout, precise mouse-wheel handling and readable dark dropdown options. Vocal Throw scrolling no longer flickers the performance disc or resets unrelated state.
- **Safer first-run audio:** conservative Windows MMDevice discovery and uniquely matched JUCE endpoint names, no virtual speaker misclassified as a physical playback sink, guarded first-run device APPLY and readback. On a pristine eligible mixer, verified standard VB-CABLE capture can be assigned to CH01 and the existing MAIN path; it cannot synthesize missing audio. Previously saved explicit ASIO choices, user wires and SOURCE ONLY routing are preserved.
- **Optional standard VB-CABLE setup:** installer can offer the **official standard** VB-Audio package with explicit consent and separate Windows UAC approval. The original package SHA-256 and signed vendor setup are verified; pending reboot and unhealthy installations are handled without rerunning the driver setup in Remove mode. Driver installation and restart can still require normal user action.
- **Build and release reliability:** Windows FAT/native jobs are deduplicated by PR/source SHA; exact-SHA package handoff, cache digests and independent artifact-delivery retries avoid recompiling JUCE solely for a transient upload failure. Current GUI CSS ownership conflicts were fixed without changing the approved physical button geometry.

## Install and download

Use the **[official ArSonMix landing page](https://masarray.github.io/arsonmix/#download)** and select the newest verified **Windows installer ZIP**. Download the ZIP directly from the page, extract it, then run Setup. The portable ZIP is intended for manual installation without the installed-app update supervisor. Keep your existing `.smix` sessions and private Studio data: per-user Inno upgrades are designed to preserve them.

**VB-CABLE attribution:** The optional virtual audio driver is supplied by **VB-Audio Software** (www.vb-cable.com), under the vendor's own licensing and donationware/professional-use conditions. ArSonMix does not silently alter Windows default audio devices; no extra A+B or C+D cable product is included. If Windows changes its default output during the vendor setup, select your actual physical speakers in Windows/audio setup.

## Qualification and limitations

The merged PR's fast native/UI, targeted built-in-FX, Harmony, VB-CABLE intake and Inno smoke gates passed. Its exact-head full Chromium regression passed, covering EQ, Compressor, Harmonice, Vocal Throw, WIRE/MAIN, SOURCE ONLY, mixer I/O, desktop/mobile layouts and Firefox compatibility. **Release publishing remains conditional on a fresh exact-source Windows MSVC build, full CTest, installer packaging, provenance, upgrade, and uploaded asset verification.**

A selected endpoint/green control does **not** imply an audible signal. Real sound requires a valid source with samples, a supported physical output, appropriate routing, and a working driver. Actual hardware ASIO 4–8-output performance, physical 44.1/48-kHz monitoring, OBS/WASAPI secondary feeds, third-party VST3 combinations and zero-crackle operation are not universally certified by virtual CI. These remain public field-feedback areas, not demands on a user who does not own specialized hardware.

This release does not claim Windows Authenticode signing. If any issue occurs, retain the prior functioning release and report device/driver, sample rate, buffer size, relevant routing, and reproduction steps.

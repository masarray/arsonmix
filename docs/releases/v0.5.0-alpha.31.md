# ArSonMix v0.5.0-alpha.31 — Premium Calm status bar restored

This Windows x64 **public alpha preview** repairs a real user-visible packaging regression in the already-accepted UX-1 compact native mixer status strip. It includes all FUX-1 / alpha.30 functionality and preserves the official single `/preview/` WebView2 mixer, primary single-ASIO PCM/FX graph, native ACK/readback and safe session handling.

## User-visible correction

- **Restored the small monochrome SVG-mask icons** in the 20 px bottom status bar for the qualified latency hint, application process CPU, realtime callback budget, and process RAM.
- **Restored calm semantic tones:** muted blue for driver/FX latency; teal for normal CPU/RT; amber for high load, soft red for critical attention, and subdued slate for unknown. RAM is informational, never arbitrarily classed as bad.
- **Preserved status truth:** performance/latency metrics appear when output is both armed and native-accepted. Muted, disconnected, offline, unavailable input, or invalid graph states show the existing actionable warnings. Missing evidence is `—`, not fake zero. `LAT ~` is a JUCE driver + FX/PDC hint, *not* measured analog round-trip, and `RT last` is last callback duration relative to period, *not* a confirmed driver XRUN.
- **Root cause:** [UX-1 PR #849](https://github.com/masarray/arsonmix/pull/849) merged the real low-cost 1 Hz native status data and JS renderer, but its SVG icon CSS was erroneously stored in retired `site/preview/mixer.html`. Official Pages/JUCE bundlers compile only the canonical `site/preview-v2` CSS owners, so alpha.30 unintentionally lacked the icons. [PR #856](https://github.com/masarray/arsonmix/pull/856) ports the approved rules to the real `mixer-section-controls.css` source owner used by the single generated `arsonmix-approved-runtime.css`.
- **No cosmetic bulk:** same 20px footer, no cards/new DOM polling/network image dependencies, no audio callback computation or new DSP/session state. Normal last-action center message and safety warning precedence remain.

## Safe testing and distribution boundaries

The owner accepted the full-size clipped/pannable six built-in FX editors in alpha.30, now retained unchanged. Before installation, back up important `.smix` files and begin with speakers muted/low. Use an intentional primary ASIO device, then inspect the bottom status footer after output admission. Real device and latency/CPU measurements vary; physical multi-vendor dual-ASIO, independent BUS sinks and experimental Guitar FX or unmerged ImmerSIB changes remain outside this release and must not be claimed as qualified.

# ArSonMix v0.5.0-alpha.14 — Windows Alpha Preview

Windows 10/11 x64. This preview packages the integrated main branch, including the RC audio and FX work and subsequent mixer UI corrections.

- Main window caption. Close, Minimize and Maximize/Restore have distinct hover and pressed states. Pressed Minimize and Maximize/Restore use higher-contrast glyphs.
- Floating tools and FX editors. Shared compact Close styling covers the registered mixer tools and FX cards. WIRE and FX tools support modeless window movement.
- Mixer controls. Add Audio is accessible on desktop and in mobile More. Channel rename takes one step.
- FX workflow. EQ, Compressor, Harmonice and Vocal Throw support native user presets, including a verified offline workspace. Harmonice includes stereo lead Pitch Tune and register-aware ensemble processing.
- Audio. The first-run policy checks Windows endpoints and preserves explicitly saved ASIO selections. Windows Setup offers the standard VB-CABLE from VB-Audio Software as an optional component. The release retains Multi Out routing for supported ASIO devices.

Download the verified **Windows installer ZIP** from the [ArSonMix landing page](https://masarray.github.io/arsonmix/#download), extract it, and run Setup. Linux and macOS cards list their latest available packages separately.

Physical ASIO coverage remains open for community feedback. Please report interface and driver versions, sample rate, buffer size and reproduction steps. Vocal Throw M15, the experimental Harmonice P1 latency work and the separate Thin Flat Bezel asset integration are outside this build.

The public release tag and packaged provenance identify the exact source used to build the installer. Continue development from current main.

# ArSonMix v0.5.0-beta.1 — Windows x64 Public Beta

Windows 10/11 x64 Public Beta candidate. Publication and exact source provenance are established by the official release publisher, not by this candidate document.

## Mixer and workflow
- Includes WIRE, offline SOF and SEND, session persistence and recovery, Show Restore, Studio Audio I/O, native Plugin Manager, Clean Ribbon V6, ArSon Player and built-in FX including SonKu P106 and ImmerSIB. The Alpha.33 product baseline consolidates follow-up fixes for FX Rack save/restore, External Output, Plugin Manager scan feedback and Audio I/O layout.
- Preserves the approved GUI and native real-time graph. This is a feature-frozen maturity promotion, not a redesign or a Stable/production-ready claim.
- The installer and portable contain the same three independently approved AGPL VST3 plug-ins: ArSonEQ, ArSonComp and ArSonVerb. Manual VST3 import remains available.

## Install, update and rollback
Download the published Windows installer ZIP or portable ZIP from the official [download page](https://masarray.github.io/arsonmix/#download) or [GitHub Releases](https://github.com/masarray/arsonmix/releases). Verify the SHA256SUMS and release trust metadata. Extract the installer ZIP before running Setup. Back up Studio and .smix sessions; keep the preceding [alpha.33 release](https://github.com/masarray/arsonmix/releases/tag/v0.5.0-alpha.33) for rollback. Existing Alpha updater builds may reject Beta attestations; manually use the verified installer for the initial migration and never bypass verification. Portable mode can be extracted into a separate writable directory. Select your audio device/pins deliberately, start muted and keep output volume low until verified.

## Qualification scope and limitations
The owner accepted Windows FIELD for the configuration exercised, including primary ASIO, live FX Rack save/restore, External Output/WASAPI, VST3 scanning and editor reopen. The Alpha.33 baseline passed 131 native CTests, full Chromium and Windows installer qualification; Beta-specific version, trust, updater, package and integration gates must pass before publication. Windows WebView2 and a compatible audio driver are required for their respective features. The supported Windows Beta scope includes one primary ASIO device. Earlier Linux and macOS builds retain their own version and qualification scope. [Acceptance and build receipts](https://github.com/masarray/arsonmix/issues/837#issuecomment-7234742596).

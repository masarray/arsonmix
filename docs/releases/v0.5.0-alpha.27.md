# ArSonMix v0.5.0-alpha.27 — Milestone D Windows native mixer and spatial release integrity

**Windows x64 public alpha.** This release restores a **complete, verifiable distribution** after a Milestone D test installer accidentally omitted the built-in ImmerSIB processor. The public alpha.26 release already included ImmerSIB; alpha.27 additionally enforces that every new Windows package **must** contain its actual native C++ FX catalog and approved scene resources, not just a label in the mixer.

## Improvements in alpha.27

- **ImmerSIB + 8D-SonKu P9.9 product integrity:** the Windows executable is compiled with `ARMIX_IMMERSIB_RELEASE_CANDIDATE=ON` and `ARMIX_SONKU_APPROVED_P99_MAIN=ON`. Packaging and independent distribution verification reject missing compiled ImmerSIB catalog identity `armix.builtin.imersip.v1`, absent JUCE scene assets, or a configuration mismatch. Six original scene PNG files are byte-verified inside the actual application executable.
- **No unapproved spatial retuning:** 29 native ImmerSIB/SonKu DSP, processor, scene, and acoustic files are checked against the accepted alpha.26 source. The golden regression continues to verify Venue PCM identity and whole-engine acoustic limits; a GNU-only absolute float hash is no longer incorrectly imposed on Windows MSVC. Existing immersive presets and published sound character have **not** been modified.
- **Offline mixer session reliability (Milestone D1):** strengthen saved PRE/POST send tap state and WIRE routing identity across native session serialization. This supports ongoing work on stable routing, while real device/backend-specific FAT remains an independent acceptance step.
- **Protected release governance (Milestone D4):** an exact-head required merge status on protected `main` now fails closed for missing/failed relevant tests, with real red-PR blocking and green documentation-PR acceptance verified. This changes the development/release gates, not the audio graph.

## Installation and upgrade

Download the newest verified Windows x64 Setup ZIP from the [official ArSonMix download page](https://masarray.github.io/arsonmix/#download). Extract and run the Setup EXE; in-place installation must preserve Studio, user presets and `.smix` sessions. A standalone portable ZIP and independently published SHA-256 checksum/provenance files are provided with the GitHub release. Check the `SHA256SUMS.txt` file when downloading outside the official landing page.

In the mixer, **FX Picker → Spatial → ImmerSIB** must load a real built-in processor with its native editor, not a static web label. **8D-SonKu** remains a separate built-in product; no separate ImmerSIB VST3 installation is required. Factory VST3 bundles are included only when independently approved; no external vendor VST3 or VB-CABLE redistribution is implied.

## Boundaries and follow-up

This is a Windows **alpha prerelease**, not a hardware-certified low-latency audio production release. Continue to qualify individual ASIO/WASAPI devices, INPUT→CH05→MAIN, SOURCE ONLY, BUS, SEND PRE/POST, FX bypass, and actual licensed third-party WaveShell plugin startup using the field acceptance plan [#412](https://github.com/masarray/arsonmix/issues/412) and [#547](https://github.com/masarray/arsonmix/issues/547). Planned multi-interface capture and modular MVVM design remain research/architecture work, not shipping alpha.27 features.

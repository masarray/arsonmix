# ArSonMix v0.5.0-alpha.26 — Embedded AGPL and clean native distribution (Windows alpha)

**Scope:** Distribution and legal UX milestone built on the approved v0.5.0-alpha.25 Windows alpha. This release retains its ImmerSIB native editor lifetime hotfix and the previously verified mixer/FX sound engines. It does not alter PCM routing, effect voicing, session format, SonKu presets, ImmerSIB sound, or the approved mixer canvas.

## New in alpha.26

- **Offline About & Licenses:** one understated native-only command at **More → About & Licenses**, with scrollable full GNU Affero General Public License v3, scope notice, MIT KEMAR/HRIR and Signalsmith texts, Inter OFL, and the optional VB-CABLE vendor notice. The original full documents are compiled into the JUCE executable, not downloaded at runtime.
- **Exact versioned source:** **View source** opens the GitHub tree for the embedded build SHA. The canonical repository `LICENSE` remains unchanged and freely accessible. Third-party rights and attribution remain separate.
- **Clean Windows installation and portable distribution:** no loose top-level AGPL/LICENSE/NOTICE files. Inno contains legal texts inside Setup and removes only seven explicitly named historical top-level documentation files during in-place upgrade; never deletes user Studio, `.smix`, preset or project files.
- **Fail-closed release qualification:** packaging scans the real compiled executable for all seven exact original document byte sequences; source, manifest, and EXE hashes must match. Windows installer and in-place upgrade regression coverage, Chromium 1680×900 and 1100×650 legal UI, native JUCE build and FX tests are gated.

## Preserved from alpha.25

- ImmerSIB floating JUCE concert editor reliably opens, stays alive alongside VST3 editor windows and is safely retired with its processor lease.
- SonKu P9.9 acoustic checkpoint, native ImmerSIB scenes, WIRE/BUS/MAIN mixer, Harmonice, Vocal Delay, EQ, Compressor, Guitar FX, VST3 hosting, ArSon Player, and `.smix` Save/Open remain unchanged.
- VB-CABLE continues to use its independently verified official vendor package; FactoryFX/VST3 plugins retain their own licenses and permissions. No unapproved third-party plugins are bundled.

## Installation

Get the newest verified Windows x64 Setup ZIP from the [official download page](https://masarray.github.io/arsonmix/#download). Extract it, run Setup, and upgrade in place; previous Studio and user session files must remain untouched. Open the desktop app, select **More → About & Licenses**, and verify all documents work with internet disconnected. Use **View source** only when you want the precise published source commit.

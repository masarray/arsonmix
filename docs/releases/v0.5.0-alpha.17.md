# ArSonMix v0.5.0-alpha.17 — Windows Alpha Preview

This preview includes Smart Installer with automatic detection of the standard VB-CABLE driver, the shared floating-panel SVG Close control, and Harmonice v8 mixer artwork for MUTE, SOLO and WIRE PRE/POST. PFL is hidden in this UI preview.

The Windows build now assembles the embedded mixer with explicit UTF-8. The preview publisher builds the application target only, then verifies the installer and packages.

Download the Windows installer ZIP from the [ArSonMix landing page](https://masarray.github.io/arsonmix/#download). Interactive driver approval and physical ASIO behavior depend on the system.

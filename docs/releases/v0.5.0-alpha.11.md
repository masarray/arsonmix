# ArSonMix v0.5.0-alpha.11 — Windows Alpha Preview

This Windows x64 preview brings global hotkeys, the updated Harmonice editor and engine, shared built-in FX presets, and device and FX host reliability improvements.

- Assign global shortcuts to mixer actions and supported VST3 parameters. The parameter browser includes Last Touched, and Show files retain supported bindings.
- Harmonice adds stereo lead Pitch Tune and updated register-aware ensemble processing. The editor uses a compact switch.
- Save and recall native user presets in EQ, Compressor, Harmonice, and Vocal Throw. Recall status reflects what the native engine accepted.
- Device apply rejects malformed device identity fields. Built-in FX preparation rejects invalid audio settings before allocating a processor. Mixer FX and WIRE status use native readback.

The integrated source passed Windows MSVC, native CTest, package integrity, and installer upgrade/rollback checks. This is an alpha field-test build. Physical ASIO and vendor plug-in coverage remain incomplete, and the independent Multi Out milestone is outside this release.

Windows x64 portable and installer packages are accompanied by checksums and source provenance.

# ArSonMix v0.5.0-alpha.25 — ImmerSIB native editor reopen hotfix (Windows public alpha)

**Scope:** Windows 10/11 x64 public alpha hotfix of the previously published [v0.5.0-alpha.24](https://github.com/masarray/arsonmix/releases/tag/v0.5.0-alpha.24). This release addresses JUCE **FX editor lifecycle and UI routing** only; its native SonKu and ImmerSIB audio processing, factory concert scenes, source-distance policy and session identity are unchanged. It is not a hardware-ASIO certification.

## Fixed in this release

- **ImmerSIB opens the real native concert editor.** Clicking the accepted ImmerSIB insert in FX Rack routes to the exact JUCE `routingFxEditor` instance on the authoritative ChannelId graph, not a generic settings-update notification or an unrelated 8D-SonKu WebView overlay.
- **ImmerSIB stays open while editing VST3 plugins.** ImmerSIB owns a separate mixer-owned native floating editor and a retained processor lease, independent of the ordinary VST3 editor window. Opening/closing dearVR PRO 2 or another VST3 does not dispose ImmerSIB's editor. Clicking the same ImmerSIB insert again raises/reopens the matching window.
- **No misleading successful-open toast.** A successful native editor open no longer generates a generic FX-settings success message. Rejected/stale editor requests continue to show a meaningful error.
- **Safe retirement.** On an actual graph/processor replacement, session load, FX deletion or shutdown, editors are destroyed before processor ownership is relinquished. The timer checks both independent leases; a stale window cannot masquerade as an active FX slot.

## Preserved from alpha.24

- Approved **8D-SonKu P9.9** orbit/venue sound and **ImmerSIB's seven concert scenes**, measured-HRTF/JUCE DSP, bypass power/ACK and existing source-distance limits (1.1–2.5 m, Early Room to 180%).
- Established WIRE/BUS/MAIN mixer routing, source/FX power behavior, Harmonice, Vocal Delay, Compressor, EQ, Guitar FX, VST3 hosting, ArSon Player and `.smix` persistence.
- Single authoritative native PCM graph, exact source SHA/release checksums, AGPL-3.0 license, MIT HRIR attribution, no unauthorized bundled VST3.

## Install and verify

Use the [official download page](https://masarray.github.io/arsonmix/#download) and ensure Windows shows **v0.5.0-alpha.25** before testing. Older development builds such as `v0.5.0-dev+g5c7455d4` and alpha.24 do **not** contain this GUI window-lifetime fix. Installer ZIP is preferred; extract and run Setup. Portable ZIP is available on [GitHub Releases](https://github.com/masarray/arsonmix/releases/tag/v0.5.0-alpha.25).

At a safe monitoring volume, load CH02 with dearVR PRO 2, Compressor and ImmerSIB. Click ImmerSIB → verify its JUCE concert editor appears; open the dearVR window → verify ImmerSIB remains open; refocus ImmerSIB → verify the original editor appears without false success toast. Repeat after hiding and reopening both windows, rack/slot/global bypass, and session Save/Open. Do not assume a click toast proves audio DSP is active.

## Verification and limitations

The source integration is [PR #742](https://github.com/masarray/arsonmix/pull/742). Source/runtime contracts, native Windows JUCE build, genuine editor/DPI tests, portable package verification and SonKu RC-OFF compatibility are required before public publication. The publisher independently rebuilds **exact pinned SHA** plus installer install/upgrade/uninstall and checksum assets; if it fails, no alpha.25 prerelease should appear.

Native/Chromium/Windows CI and editor-lifetime assertions are not a physical headphone/ASIO test. Report any plugin-window focus issues, acoustic changes, hardware dropouts or session restore failures with plugin version, OS, audio backend, sample rate, buffer size and reproduction steps using [GitHub Issues](https://github.com/masarray/arsonmix/issues). Keep private session backups and never overwrite an occupied session without saving a copy first.

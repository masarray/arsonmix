# ArSonMix v0.5.0-alpha.23 — Public Windows Alpha Preview

**Scope:** Windows 10/11 x64 user-testing preview. This is a public alpha release, not production/stage certification or proof of physical-ASIO latency, HRTF listening quality, or all device drivers. The real publisher must pass exact-source native build, installer, upgrade/uninstall, release asset, checksum, and provenance checks before GitHub creates a release.

## Reconciled features since alpha.22

- **Vocal Delay** is the new product name for the native phrase-aware delay formerly displayed as Vocal Throw. FX picker, rack, editor title, accessible controls, native JUCE processor name and built-in catalog now show **Vocal Delay**. The saved catalog ID `armix.builtin.vocal-throw.v1`, native JSON control protocol, older `.smix` files, preset serialization, and historic implementation filenames stay unchanged. Older browser preview slots named `ArSon Vocal Throw` remain recognized. The **THROW** cue is an effect action, not the product title.
- **8D-SonKu:** cyan transparent top-rear listener PNG, physically consistent FRONT-far / REAR-near speaker layering, smooth dynamic scale/opacity and independent stereo speaker occlusion. Real sound remains in one native JUCE measured-HRTF/SPACE graph; ROOM distance, reflections, reverb and output gain improvements carried from the integrated M4 work.
- **Guitar FX:** native built-in Guitar FX and the previously merged latest artist-source layered PNG controls, knobs and switches are retained exactly. Experimental geometry-first visual rewrite in still-open PR #668 is not promoted without separate visual acceptance.
- **Mixer and routing:** retain verified ChannelId/EdgeId routing, hardware-input WIRE/BUS/MAIN controls, native FX chain, Input Gain, PRE/POST and SEND ON, responsive operator console, accepted native ACK/readback, mute/solo, and `.smix` Save/Open. Do not introduce a second WebAudio or compatibility audio routing authority.
- **Other built-in FX:** EQ, Compressor, Harmonice (vocal harmony), native presets and previously integrated live GUI/engine fixes remain available.
- **Maintainability and UI:** SonKu CSS ownership reconciled without new override sheets, 72 shadowed declarations removed, fast ownership gate enabled; preserve the approved single `/preview/` GUI, latest hardware PNG/FX art and window control behavior.

## Download, authenticity and first run

Download from the [official ArSonMix page](https://masarray.github.io/arsonmix/#download) when the verified alpha.23 asset appears. The Windows card links directly to the verified installer ZIP; unzip before running Setup. GitHub [Releases](https://github.com/masarray/arsonmix/releases) retains installer EXE, installer ZIP, portable ZIP, SHA256SUMS.txt, BUILD_PROVENANCE.json, INSTALLER_PROVENANCE.json and optional first-party FX staging report. If the publisher fails, **no alpha.23 release is created**.

Start with a safe monitoring volume. Select an actual hardware input/output and test: direct channel to MAIN, SOURCE ONLY mute from MAIN, WIRE to BUS then MAIN, plug-in bypass, Vocal Delay and SonKu, gain clipping, Save/Open `.smix`, and device restart. Report driver/device name, sample rate, buffer frames, and reproducible screenshots/logs.

**Limitations:** Automated Linux/native PCM/C++/Chromium CI is not a physical Windows ASIO headphone test. Native Windows packaging and installer qualification are independently checked by the release publisher. Report cracks, XRuns, routing silence and VST3 incompatibilities; no claim is made that all 4–8 output hardware, Windows configurations or third-party VST3 have been validated. Linux and macOS are not part of this Windows-only release. Optional VST3 are included only if separately license/digest approved.

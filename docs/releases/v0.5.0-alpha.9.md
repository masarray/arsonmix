# ArSonMix v0.5.0-alpha.9

Windows x64 public preview for field testing. Hardware FAT is pending.

## Changes

- Edit channels, buses, WIRE and SOURCE ONLY in the native logical mixer without an audio device. Save/Open uses the existing `.smix` format. Edits are confirmed after a durable native checkpoint and readback.
- Protect an offline checkpoint when a device reconnects. Reject stale edits from a previously opened session.
- Recover a previously bound ASIO mixer only after verifying the registered driver and playback pins. Generic ASIO recovery preserves the saved capture patch if its pins are unavailable.
- Harmonice displays its current brand with its existing session catalog ID, an 8 ms bypass fade and fresh Music guide acquisition after loss of the guide. Production DSP latency remains 32 ms.
- ArSon Player can relink missing songs by a unique full filename in a completed folder scan. Track identity, KEY and TEMPO are retained.
- Updated native titlebar and operator-facing desktop status.

## Field-test limits

- Initial hardware binding of a session authored offline and editing a retained graph after unplug remain limited. If the device disconnects, reconnect the verified device to resume its previously bound PCM graph.
- Physical ASIO/ASIO4ALL routing, timing, vendor VST3 state and uninterrupted playback have not completed hardware acceptance for this preview.
- Harmonice 24/16 ms research and Vocal Throw M15 remain in separate development branches.

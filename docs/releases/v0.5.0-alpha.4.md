# ArSonMix v0.5.0-alpha.4 — Windows Native Context Menu Preview

**Alpha test build only. Not qualified for critical live performance.** This candidate includes the native right-click workflow merged from PR #449, on top of the Windows mixer and installer delivered in Alpha 1.

## New in this preview
- App-owned context menu in the authenticated Windows native `/preview/` WebView2: the Chrome/WebView browser context menu is suppressed there; the public website is unaffected.
- Right-click an audio track header → **Delete Track** → confirm. The engine removes the accepted native input channel, its hardware source patch, incoming/outgoing WIRE connections and channel-owned FX leases in one prepared graph publication; unrelated channels remain intact.
- The GUI waits for a matching native acknowledgement and graph readback. It does not fake deletion when the engine rejects or times out.
- Right-click an installed **dearVR PRO 2** FX entry → **Orbit**. The Orbit controls act on the verified plugin instance lease, not a guessed global slot, and stop when the instance or device changes.
- Existing **Add Audio Track**, built-in EQ, ASIO-first mixer routing, Show storage and Inno installation/upgrade behavior remain included.

## Download and installation
- **Windows x64 Setup.exe**: install or upgrade the existing per-user ArSonMix test installation.
- **Windows x64 Portable.zip**: extract to a writable folder and launch the executable without installation.
- Use `SHA256SUMS.txt`, `BUILD_PROVENANCE.json` and `INSTALLER_PROVENANCE.json` to verify the exact native build.
- The native mixer does **not** require FactoryFX extras. An unavailable optional bonus VST3 is never a reason to reject the mixer build.

## Suggested focused verification
1. On Windows 10/11 x64, verify hardware input → channel → MAIN playback. Confirm **Add Audio Track** still works before/after deleting a newly created track.
2. Right-click a created audio track header, choose **Delete Track**, confirm. Check its meter, WIRE connections and FX disappear only after accepted native readback; unrelated channel audio and WIRE remain.
3. Open an installed dearVR PRO 2 insert. Right-click its FX entry → **Orbit**. Test start, stop, direction, duration, and closing the panel while listening. Check no ghost automation continues after removing the insert or changing devices.
4. Restart and reopen your saved Studio/Show. Report the precise device driver, sample rate, buffer length, installed dearVR version, and steps if behavior differs.

## Known limitations and safety
- This is **not** a hardware FAT certificate: automated Windows MSVC and CTest plus packaging/install tests do not prove audible ASIO latency, device-dependent Orbit parameter compatibility, or glitch-free live operation.
- dearVR PRO 2 is **not bundled** and requires the user's own valid installation/license. Orbit is available only if the supported plugin is loaded and its native identity is verified.
- First-party optional FactoryFX availability depends on independent approval; the built-in mixer and EQ work without them.
- Back up important Studio/Show content before testing. Do not test on a critical live performance.

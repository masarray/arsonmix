# ArSonMix v0.5.0-alpha.22 — Native caption hover & pressed field fix

This Windows alpha includes the owner-requested **main-window caption controls restoration**. Alpha.19–21 were published before this fix, so they do **not** contain it.

## Native window control repair

- **Close:** muted red hover; bright red when pressed.
- **Minimise:** dark green hover; bright green when pressed.
- **Maximise/Restore:** dark amber hover; bright yellow when pressed.
- Retains the exact approved SVG icons, original 34 px hit targets, titlebar, real app version and native window actions.
- Explicitly constructs all three caption buttons from the custom JUCE LookAndFeel (rather than allowing stock buttons constructed before LookAndFeel installation).
- Keeps the three main-window native caption controls enabled through WebView2 child-window focus changes. JUCE 8's default `DocumentWindow::activeWindowStatusChanged` can disable caption buttons when the parent JUCE window is marked inactive, even though browser input remains active.
- No always-on-top mixer, repeated foreground stealing, JS hover polling, or DSP/ASIO/WIRE changes.

## Installation and use

Download the official Windows x64 Setup ZIP from [this release](https://github.com/masarray/arsonmix/releases/tag/v0.5.0-alpha.22). Install over the prior alpha; personal `.smix` sessions and plugins are retained. This is a community open-source alpha with no requirement for commercial code signing or DRM. An unsigned installer may show a Windows reputation prompt.

# ArSonMix v0.5.0-alpha.6 — Native Compressor & Unified FX Controls

> **RELEASE CANDIDATE / UNPUBLISHED.** Community-test alpha, not certified for live stage or mission-critical use. No GitHub Release or installer is published merely by creating this branch. Do not replace the existing `v0.5.0-alpha.5` binaries.

## Changes since alpha.5

- **Built-in native Compressor.** Add `armix.builtin.channel-compressor.v1` to the approved FX catalog and ordered ChannelId native PCM insert graph. Stereo-linked feed-forward dynamics, threshold, ratio, soft knee, attack, release, makeup and parallel wet/dry. No lookahead or oversampling; the processor declares **zero additional sample latency** (not zero interface/driver round-trip latency).
- **Compact DAW-style FX editor.** A modeless, approximately 558px-wide Compressor panel inside the one approved assembled `/preview/` GUI, with transfer curve, draggable threshold, gain-reduction display, seven working controls and a header preset dropdown (Default, Vocal, Speech, Gentle, Drum, Custom).
- **Consistent window controls.** Common Close styling across dialogs; Close flashes red on press. EQ and Compressor Power visually distinguish accepted insert ON, insert BYPASS, parent FX rack OFF and unavailable state. No optimistic claim that a UI click has modified audio until the native graph readback confirms it.
- **Native state lifecycle.** Bounded control queues, instance/revision-gated DSP ACK and readback, session state restore, bypass behavior, deterministic UI and no callback-side heap allocation/logging. The native source stays the mixer/audio authority; browser preview is visual-only.
- **Distribution UX updates already integrated into main.** Explicit Windows/Linux/macOS download choices, Git-connected Cloudflare Pages build support and documentation reconciliation. No automatic new binary or extra VST3 entitlement is implied by website availability.

## Scope and limitations

- FactoryFX bonus VST3 modules remain optional. Stage only independently approved and verified bundles; the last tested Windows FAT report included **no extra FactoryFX packages**. Built-in EQ and Compressor require none.
- Hardware-dependent IN → FX → WIRE/BUS → MAIN, hotplug/reconnect, ASIO xrun/crackle and Show restore still require owner field evidence. See [audio workflow #412](https://github.com/masarray/arsonmix/issues/412), [crackle #15](https://github.com/masarray/arsonmix/issues/15), [dynamic channels #192](https://github.com/masarray/arsonmix/issues/192), and [GUI/native parity #389](https://github.com/masarray/arsonmix/issues/389). **Do not advertise a certified or production-stable release.**
- Browser Chromium tests and native CTest are software verification, **not** physical ASIO listening or measured live-stream latency. Input Gain, look-ahead, auto modes and external sidechain are not claimed as operational Compressor UI controls.
- Linux/macOS are eligible only after real same-SHA platform-native CMake/CTest and package integrity checks. macOS binaries use ad-hoc signing, not Apple Developer ID notarization.

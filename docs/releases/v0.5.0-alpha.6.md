## Included built-in Compressor scope

- Native `armix.builtin.channel-compressor.v1` insert: stereo-linked feed-forward dynamics with Threshold, Ratio, Knee, Attack, Release, Gain/Makeup and Mix; off-RT prepared control / graph-instance-bound DSP ACK and restore.
- No lookahead and **zero added compressor algorithmic samples**, not zero ASIO/device latency.
- LCD compression curve with true pre/post processing PCM input/output dBFS and gain reduction, stale-meter expiry, unified global Close/Power state, preset selector and adjustable threshold graph.
- No invented functional sidechain/input trim/auto-gain/auto-release controls; sidechain remains internal stereo-linked only.

- **Do not merge** still-draft Harmony [#467](https://github.com/masarray/arsonmix/pull/467), Vocal Throw [#469](https://github.com/masarray/arsonmix/pull/469), stacked M2 [#474](https://github.com/masarray/arsonmix/pull/474), M3 [#476](https://github.com/masarray/arsonmix/pull/476), or hardware GUI [#479](https://github.com/masarray/arsonmix/pull/479) into alpha.6 merely to build a release. - Optional sibling FactoryFX VST3 bundles remain excluded unless their **exact identities, approved binaries and integrity** are established. Historical alpha.6 stage reported `included: []`. Do not describe unverified plug-ins as shipped.
- Known field/engineering risks are tracked at [#412](https://github.com/masarray/arsonmix/issues/412) (DAW/hardware), [#15](https://github.com/masarray/arsonmix/issues/15) (crackle), [#192](https://github.com/masarray/arsonmix/issues/192) (dynamic roster), [#180](https://github.com/masarray/arsonmix/issues/180) (Show), [#389](https://github.com/masarray/arsonmix/issues/389) (UI parity), [#185](https://github.com/masarray/arsonmix/issues/185) (FactoryFX) and [#453](https://github.com/masarray/arsonmix/issues/453) (OS distribution).

3. **Linux/macOS exact SHA.** Run one native JUCE/CTest + package qualification for each OS when scheduling the release milestone; `/arsonmix-port linux|macos releases/alpha/v0.5.0-alpha.6 <candidate-SHA>` at [release controller #450](https://github.com/masarray/arsonmix/issues/450). Earlier source/package successes are not substitutes. Do not upload placeholder alpha.0 artifacts as alpha.6.
4. **Owner hardware FAT.** Test the **exact candidate binary** on the real ASIO device: IN → channel Compressor/EQ → fader → WIRE/BUS → MAIN → hardware output; no manual Monitor/Arm; SOURCE ONLY signal and channel meter with muted main; ON/OFF rack+slot bypass; stereo/mono; Save/Open Show; driver reconnect; 64/128/256-sample buffer crackle/latency; WASAPI/VB Cable secondary listener isolation. Record device, sample rate, buffer, whether audible output matched UI and relevant errors. Software CI cannot certify this.
5. **Explicit publication is separate.** No GitHub tag, public binary, Pages catalog, or prerelease is created by this preparation. Only after approving the final immutable SHA and qualification results, the repository owner may authorize `/arsonmix-release v0.5.0-alpha.6 <candidate-SHA>` on [#450](https://github.com/masarray/arsonmix/issues/450). That publisher actually uploads Windows prerelease and refreshes the landing. Linux/macOS public uploads need their own matching-source, separately authorized port publication.

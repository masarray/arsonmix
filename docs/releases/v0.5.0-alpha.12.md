# ArSonMix v0.5.0-alpha.12 — Windows Multi Out Preview

This Windows x64 preview adds independent ASIO External Out routing alongside the global hotkeys, Harmonice, built-in FX presets, and device and FX host improvements from alpha.11.

- Assign a channel's post-FX signal to a verified stereo pair on the active ASIO device. The Outputs overview shows the actual device pins and whether each assignment is pending, applied, shared, muted, or needs remapping.
- Saved Shows retain external assignments. When the device or pins change, affected assignments require remapping. Other pairs that still match the confirmed device can recover independently.

Windows CI verified the build, native tests, and installer for the Multi Out pull request. The integrated source also passed deterministic PCM tests, including four- and eight-output fixtures, and the GUI and installer contract tests. This is a public preview. Compatibility with physical ASIO hardware is still being assessed.

## Help test Multi Out

If you have an ASIO interface with 4–8 outputs, please report your interface model and driver version, sample rate and buffer size, the output pairs you used, and whether routing, mute, and device restart worked as expected. If you hear dropouts or unexpected routing, include reproduction steps. Start with your output levels low.

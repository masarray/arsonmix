# ArSonMix v0.5.0-alpha.20 — Guitar FX Rig Windows Field-Testing Preview

## Fix delivered: Guitar FX Rig is now included in the Windows installer

**Release purpose:** Correct the Alpha.19 distribution gap where the owner could not find Guitar FX Rig in the FX Picker. Alpha.19 was built from `746877e28fddbf9dc19816be024afbbad43d3e69`, **before** Guitar FX was merged. A GitHub PR merge does not update a previously installed or already published EXE.

This Windows alpha preview is compiled from this release branch (descended from `main@9c17e926cb6a8edc79941fb82fde91b3c7328adc`), which contains **merged PR #607** (`977b6227d436b73cbf6c63d8f0fb6fd6d5b8a2e5`). It also retains approved V67 WIRE behavior, the splash-to-foreground startup fix and current native GUI.

## Actual in-app Guitar FX

- Open a channel's **FX Rack → Add FX / FX Picker**. Find **Guitar FX Rig** under **Guitar**, or search `guitar`. The feature is an **internal Native** effect; it is **not** an external downloadable VST3, and **does not** require a VST3 scan.
- Select **Guitar FX Rig** in the channel's FX slot. A real native JUCE guitar editor should open through the existing FX instance/editor pathway, and offer Clean Studio, Warm Blues, Vintage Crunch, Modern Lead, Gate/Drive/Amp/CAB and two A/B banks.
- DSP runs within the one existing native JUCE mixer audio graph; 2× preamp oversampling and 48-sample fixed Guitar FX PDC. The factory cabinet is an original algorithmic FIR, **not** a commercial captured impulse response, a NAM network or a licensed commercial guitar model.

## First essential acceptance

1. **Confirm first** that Guitar FX Rig is visible and searchable in the installed app's FX Picker. If missing, **stop** and report Help/About version and the executable's build identity: do not waste time testing audio.
2. With a real guitar connected to the audio interface's instrument/Hi-Z input (NOT a phantom-powered microphone input), route one ArSonMix channel → Guitar FX Rig → WIRE → MAIN → ASIO hardware out. Start with a safe low monitor volume.
3. Verify real audible changes across four profiles, knobs, pedal bypass, CAB ON/OFF, native meters, A/B switching, editor close/reopen and `.smix` save/open.
4. Test device/sample-rate changes (44.1/48/96kHz, 64/128/256 samples where supported), record CPU/xrun/dropouts/round-trip latency and driver. See `docs/guitar-fx/GFX_FIELD_ACCEPTANCE.md`.
5. If FX Picker shows the effect but insert rejects it or remains silent, report the native ACK/error rather than declaring the feature passed.

## Evidence and restrictions

- Guitar FX first-sound parent build [Windows FAT #43377503898](https://github.com/masarray/arsonmix/actions/runs/43377503898) passed 92/92 CTests; later merged to main after 5/5 lightweight workflows. **That earlier build and Alpha.19 are different binaries.**
- THIS alpha release must pass its own exact-SHA Windows build, embedded WebView2 GUI manifest checks, genuine Windows GUI PE validation, Inno installer/package checks, and byte-for-byte distribution/provenance verification before it becomes public.
- **Software tests do not prove physical Hi-Z guitar/ASIO tone quality, CPU, xrun or measured hardware round-trip latency.** Alpha means owner-testing preview, NOT stable/pro audio qualification.
- No NAM library/model, captured speaker IR, tuner, chorus, delay or guitar reverb is claimed as playable unless a subsequent qualified milestone actually supplies its native DSP.

**Release type:** Windows x64 Alpha Preview for product field testing. Upgrade over earlier Alpha builds using the verified installer; your user `.smix` sessions/plugins are not part of the distribution. Portable ZIP is available for isolated testing.

# ArSonMix v0.5.0-alpha.5 — Native Windows/Linux/macOS Community Preview

**Public open-source TEST release, not stable or certified for critical live performance.**

This milestone keeps the approved `/preview/` native mixer, ChannelId WIRE/PCM graph and Windows ASIO-first behavior from Alpha.4. Linux and macOS targets use the same embedded JUCE GUI, native JUCE VST3 hosting and respective system audio backends, rather than relabeling the Windows EXE.

## Public binaries appear only after per-OS qualification

- Windows x64: Inno Setup.exe and Portable.zip with exact executable identity, regression CTest and upgrade/uninstall verification.
- Linux x86_64: **only after real Ubuntu native CMake build/CTest and ELF dynamic dependency verification**, `Linux-x86_64.tar.gz`.
- macOS universal (Apple Silicon + Intel): **only after one real native Apple CMake build/CTest and dual-slice Mach-O .app/DMG verification**. No paid Developer ID: free ad-hoc signing; no Apple notarization. Gatekeeper may require an explicit user override in Privacy & Security.
- A platform without native verified binary remains **COMING SOON**, not a fake installer or a link to GitHub Actions.

No FactoryFX external bonus or licensed commercial VST3 is bundled by this release policy. ArSonMix's built-in EQ/mixer is available regardless of optional VST3.

## Testing advice

Choose your actual input/output interface; test audio→channel→WIRE/BUS→MAIN, FX bypass, fader/pan/mute/solo, channel creation/removal, session restore, device changes and GUI native context menus. On macOS, verify the SHA256 checksum before choosing `Open Anyway` for this unnotarized build; never disable Gatekeeper globally. On Linux install compatible GTK3/WebKitGTK 4.1/ALSA/JACK system libraries.

Report the exact source SHA, OS/CPU, driver, sample rate, buffer size, steps and observed audio. Automated compiler and GUI tests **do not** prove crackle-free physical hardware or third-party plugin compatibility. Back up Shows and avoid production live use.

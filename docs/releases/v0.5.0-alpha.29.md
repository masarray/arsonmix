# ArSonMix v0.5.0-alpha.29 — Graphic EQ 31 integrated Windows preview

This Windows x64 prerelease promotes the **fully merged native Graphic EQ 31** into the approved ArSonMix mixer and packages an installable build from an immutable, main-descended source. This is a **controlled operator test build**, not a physical-ASIO-certified live audio release.

## Included and user-visible

- **Graphic EQ 31** ([merged PR #835](https://github.com/masarray/arsonmix/pull/835), protected-main squash `808b8bba344054a3a001f51e8e95dda9905455db`): native stereo 31-band equalizer with standard fixed centers, a separate Output Level, real-time drag/mouse-wheel update, 0 dB detents, draggable floating editor and the previously approved v13 metal/SVG UI.
- **Audio behavior**: 31-band response and explicit output trims, atomic 31-band + Output factory and user preset recall, coefficient/linear-gain tables prepared outside the realtime callback, bounded band and output smoothing, per-channel NaN/Inf recovery, **no extra PCM FIFO/lookahead frames** in the primary render graph. Complex EQ boosts can exceed 0 dBFS; this is NOT a limiter and users must maintain headroom.
- Uses the same official `/preview/` WebView2 GUI, one native primary single-ASIO PCM/FX graph and existing safe startup requirements (VB-CABLE diagnostic and WebView2 prerequisite when required). Existing non-GEQ user settings and `.smix` state should be preserved on upgrade.

## Testing boundaries and operator precautions

- **NOT RUN:** physical ASIO dry-vs-GEQ 120-second AUDIO_HEALTH p95/p99 CPU, device/driver XRUN soak, actual acoustic listening, measured end-to-end round-trip latency, multi-vendor dual-ASIO and external BUS/CH output sink qualification. Zero added PCM **frames** is not zero physical converter/driver delay or zero filter phase shift.
- Keep primary single-ASIO only; do not enable unverified secondary dual-ASIO experiments or change the existing single render graph.
- Back up existing `.smix` files, install at muted/low monitor levels, open the built-in Graphic EQ 31 from FX Rack, verify Flat/0 dB, live wheel/drag and Output trim, SAVE/OPEN recall, bypass/A-B; report any glitch/XRUN and 1 Hz AUDIO_HEALTH stats with driver, rate and buffer size.
- Optional bundled factory third-party VST3s are only staged with their independent approved provenance; availability is not inferred from repository siblings. Other experimental I/O and unaccepted Guitar FX visuals are not promised.

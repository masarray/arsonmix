# ArSonMix v0.5.0-alpha.15 — Windows Alpha Preview

## Smart Installer

Interactive Setup checks for VB-CABLE automatically. The Additional Tasks checkbox has been removed. If the standard driver is already healthy, Setup skips driver installation. If the driver is missing, Setup verifies the official VB-Audio package and opens the vendor installer with Windows administrator approval. Declining approval leaves ArSonMix installed. When the driver requires a restart, Setup prompts for it and defers opening the mixer. Silent updates continue without the interactive driver step.

## Mixer GUI

Floating panels use the shared Close SVG, with a subdued red hover and bright red press. The button sits at the right of the panel header, including ArSon Player. The Matrix Close icon remains visible while pressed.

Get the Windows installer ZIP from the [official landing page](https://masarray.github.io/arsonmix/#download). The package provenance identifies the exact source commit. Interactive driver approval and hardware behavior can vary by system.

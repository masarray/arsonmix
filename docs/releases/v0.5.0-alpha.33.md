# ArSonMix v0.5.0-alpha.33 — release candidate notes

Windows 10/11 x64 public alpha preview. This document describes the candidate scope; the tag is not a release until the official publisher has completed all mandatory gates.

## Mixer and workflow
- Retains the owner-accepted FIELD mixer baseline `0c831e193d936bca4c8234294d4e64dec24a9aa8`: WIRE, offline SOF and SEND, reliable session persistence/recovery, channel controls, Show Restore, Studio Audio I/O, native Plugin Manager, Clean Ribbon V6, ArSon Player and built-in FX including SonKu P106 and ImmerSIB.
- Preserves the approved GUI and native real-time graph. This is a stabilization release, not a redesign.
- Standard FactoryFX publication requires exactly four independently approved sibling VST3 binaries (ArSonEQ, ArSonComp, ArSonVerb, ArSonKuPik Enhancer). The installer and portable must contain the same verified inventory. Native built-in effects remain separate from these VST3s. KuPik retains its original evaluation and separate activation terms; bundling does not grant a paid activation.

## Install, update and rollback
Download the published Windows installer ZIP or portable ZIP from the official [download page](https://masarray.github.io/arsonmix/#download) or [GitHub Releases](https://github.com/masarray/arsonmix/releases). Verify the SHA256SUMS and release trust metadata. Extract the installer ZIP before running Setup. Back up Studio and .smix sessions; keep the preceding [alpha.32 release](https://github.com/masarray/arsonmix/releases/tag/v0.5.0-alpha.32) for rollback. Portable mode can be extracted into a separate writable directory. Select your audio device/pins deliberately, start muted and keep output volume low until verified.

## Qualification scope and limitations
The owner reports successful hands-on testing of the core-only FIELD baseline on 28 November 2026. That is not a physical test of the four newly bundled VST3s, every driver, buffer, hardware route or round-trip latency. Publication requires the remaining exact-source protected native/UI gates, reviewed FactoryFX licenses and provenance, package verification and hardware acceptance specified in the repository. One primary ASIO device; independently synchronized dual-vendor ASIO is not advertised as released. Windows WebView2 and a compatible audio driver are required for their respective features. Earlier Linux/macOS builds are separate releases, not alpha.33 platform parity. See the exact published release receipts for verified results.

# ArSonMix v0.5.0-alpha.18 — Windows Alpha Preview

## Smart Auto Updater milestone (M4 + M5)

This alpha contains the merged ArSonMix Smart Auto Updater improvements, delivered as open-source Windows software without commercial code signing, license activation or DRM.

- **One clear OK:** when the next official update is downloaded and checked, a small nonmodal window asks for permission to install it after ArSonMix is closed normally. Closing the notice defers consent; operating the mixer is never blocked.
- **Your performance stays live:** background downloads/checksum checks run in a separate low-priority process. The updater does not force-close ArSonMix or interfere with the ASIO callback.
- **Safe next start:** update and rollback installers are checked against the published GitHub release, SHA-256, checksums and release provenance. Both packages are checked again immediately before installation.
- **Safer recovery:** if update installation or GUI startup fails, the original version can be recovered using the verified rollback installer. The temporary GUI-only health check does not open the audio interface or replay sound after intentional Quit.
- **Older official builds:** bounded release-history discovery supports matching an original published installation even after it leaves the first page of GitHub releases.

## Install or upgrade

Use the **Windows x64 Setup ZIP** on the [official ArSonMix download page](https://masarray.github.io/arsonmix/#download); the ZIP contains the normal Inno Setup EXE. Portable builds are manual installs and do not auto-update. Users already running a published Inno-installed alpha can upgrade in place while keeping private Studio sessions, saved `.smix` files and user plugin data.

The initial upgrade from an old published version follows the updater already installed in that old version; the new one-OK experience is available once this release is installed.

This is a community alpha preview. Published GitHub Releases and SHA-256/provenance are the verification basis. No paid signing certificate is required; an unsigned executable may show the normal Windows reputation warning. Device drivers and genuine ASIO monitoring should be validated on the user's own machine before an important live performance.

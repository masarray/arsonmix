# ArSonMix v0.5.0-alpha.16 — Windows Alpha Preview

- Smart Installer detects the standard VB-CABLE driver automatically and skips setup when it is already healthy. Missing drivers use the verified vendor installer and Windows administrator approval. The old checkbox is gone.
- Floating panels use the shared SVG Close button with muted red hover and bright red press.
- Harmonice v8 mixer artwork updates MUTE, SOLO and WIRE PRE/POST states. PFL is hidden in this UI preview.

Download the Windows installer ZIP from the [ArSonMix landing page](https://masarray.github.io/arsonmix/#download). The package provenance identifies the exact source. Physical ASIO and interactive driver behavior remain subject to device feedback.

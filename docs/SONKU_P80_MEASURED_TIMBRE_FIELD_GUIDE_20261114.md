# SonKu P8.0 — measured timbre correction field check (research only)

**Status: CPU/SRC/PCM research, NOT dearVR parity, NOT user-accepted audio quality.**
P7.4 physical report: severe cancellation. P7.5 physical report: thin bass, forward/nasal mid, flat room and undesirable centered/head-locked stereo. These are acceptance FAILS, regardless of green CI. This P8.0 experiment **only targets a measured LF/mid imbalance** and establishes objective direct/ER/late evidence. The stereo spatialization and full room perceptual quality still require a new architecture and independent testing.

## Exact implementation
`ARMIX_SONKU_EXPERIMENTAL_NATIVE_XYZ_RT=ON`
+ `ARMIX_SONKU_EXPERIMENTAL_MUSIC_SAFE=ON`
+ `ARMIX_SONKU_EXPERIMENTAL_P80_TIMBRE=ON`.
All three OFF in the public installer. The same measured KEMAR bank as native PCM is sampled at 0°, 90° and 180°, both ears, 125 and 1000 Hz on the control thread. A *bounded maximum 4.5 dB* stereo-common RBJ low shelf around 180 Hz is prepared before the callback and applied only to the spatial/binaural field; SIDE anti-phase protection is not filtered/altered. This avoids a fabricated +10 dB bass patch, avoids changing ITD/ILD and stops stacking the older ROOM-only shelf. The result is **not a proprietary Clarity clone**.

## Objective acceptance
`sonku_p80_evidence.json` is generated by two isolated compiles of the same source commit: P7.5 (baseline flag OFF) and P8.0 (new measured flag ON). Sources are deterministic probes rather than copyrighted program material. The gate checks tonal bass relative to 1 kHz, 8 kHz preservation, opposite-phase SIDE invariance, and that first reflections and late tail are observable separately. Source, compile flags, and sample rate are recorded. The report DOES NOT compare dearVR audio and cannot prove musical naturalness.

## Physical test, before any promotion
1. Extract only the P8.0 Windows research artifact into a clean portable folder. Confirm `BUILD_PROVENANCE.json`: `measuredTimbre=true`, `publicRelease=false` and exact HEAD SHA. Begin at low monitoring volume. Use ASIO stereo headphone outputs; **Master Mono OFF**.
2. Same native GUI/channel/WIRE/MAIN, with one SonKu insert, 48 kHz, 256 frames. Verify real native v3 ACK and new `MEASURED TIMBRE · RESEARCH` label; if absent, record it as a FAILED test.
3. Using the **same licensed music** and the same interface/headphones/volume: FX Bypass → P7.5 (thin/nasal reference) → P8.0. Test ROOM OFF first; FRONT static, SPREAD 60, SPATIAL MIX 100%, moderate trim. Specifically evaluate whether bass guitar and kick become fuller **without mid/vocal losing clarity or SIDE shrinking**.
4. Then select SQUARE 7.2m with ROOM ON and compare EARLY and LATE settings separately where possible. Check reflections, density, front/back positioning, and whether the room feels cubical rather than a flat echo.
5. For dearVR PRO 2 A/B, log **Clarity** level and **Bass Boost OFF vs ON** separately, plus actual Realtime Auralisation 6-boundary geometry, Reverb ON/OFF, room preset, ER/late filters, master level and output binaural. Loudness match with measured levels, not knob positions.
6. Re-test 44.1/48 kHz 64/128/256 buffers when supported, 1/2/4 inserts with a normal VST3 and WIRE, restart/rebind, .smix save/open, and XRUN/p95/p99. Stop immediately on harsh coloration, bursts, severe cancellation or stereo collapse.

## Still unresolved / veto
- Stereo source objects need physically spatialized **two-input/two-ear rendering** with content-safe phase handling; P7.5 MID HRTF + unfiltered SIDE is *not* a final stereo design.
- Six-wall ER need calibrated frequency-dependent boundary absorption / reflection direction; late field needs calibrated room-wise band decay / DRR and listening qualification.
- No green CI result, room-label text, or uncalibrated bass lift proves parity with dearVR. Keep this PR Draft and public main untouched until headphone tests pass.

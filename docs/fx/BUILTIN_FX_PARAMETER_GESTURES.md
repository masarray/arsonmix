# Built-in FX parameter gesture contract
All enabled continuous controls support hover wheel, vertical drag or their established slider drag, and live native parameter application, without restarting audio. Wheel up increases; down decreases; Shift selects fine step. Control/Command wheel and dominant horizontal scroll pass through. Disabled/unavailable controls never emit edits. Wheel outside controls scrolls normally. Preserve parameter ranges, log mapping and GEQ zero detents. No global document wheel interception. The shared gesture helper is CONTROL only; one existing native ACK/readback pipeline per instance owns DSP. Retain latest intent while pending; never label draft accepted. No changes to audio callback topology. Native JUCE sliders explicitly enable wheel and continuous notification.
Auto Ducker: landscape two-layer LED frame + quantized fill, numeric LCD, shared button states. All physical audio and exact-head Chromium/Windows validation remain release gates.

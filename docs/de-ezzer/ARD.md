# de-Ezzer — architecture / ADR-001
Modular monolith, feature-isolated development. Core in engine/builtin_fx/de_ezzer; independent C++20, one production-intended implementation. Standalone tools compile it directly. Host adapter later owns lifecycle and existing ChannelId/EdgeId graph binding, source roles, session and actual ACK/readback; no second renderer or duplicate authority. UI HTML/CSS/JS presentation only, approved /preview/ assembled flat assets. Reuse FxSpsc or existing native transport where suitable; bounded commands/completions and droppable telemetry, fenced instance/epoch. Audio owner exclusively mutates Core; prepare/reset quiescent. GUI never calls Core directly.

ADR: choose causal complementary residual shelf as baseline. Compare with wideband (body pumping), split-band linear-phase (delay), time-varying parametric EQ (stability/coefficient modulation) and STFT (latency/complexity). Fixed detector biquads and fixed lowpass, smooth scalar gain; exact dry at settled unity. This is a first-order shelf, not a brick-wall band or surgical adaptive EQ. No additional sample delay, but frequency-dependent phase/group delay when active. Reassess if matched-benefit corpus, transient or frequency-response tests fail. No proprietary source copied. No Windows dispatch for standalone iteration. Integration follows AGENTS.md, autonomous fast delivery contract, issue #837; Anti Noiz #900 is methodology only, not dependency.

## Native P0A
Core emits same detector PCM and evidence-gated ESS from same causal detector pass. ESS gate uses clamp(excess/6,0,1), smoothed by existing attack/release, independent of Amount; not a separated phoneme stem. Sidechain is the existing two-band detector composite. Delta = sanitized dry minus actual internal wet (may include phase residual). Mix = wet. Monitor renders optional separate nonoverlapping caller-owned cue buffers in the SAME render; refuses overlapping, invalid mode/size/channel pointers. Fixed -12dB operator headroom, hard +/-0.5 peak bound, 5ms cue mode/start crossfade. This is the cue producer API only: no host-level permission, physical monitor routing, route revoke/fade-out or operator listen buttons yet. Do not call twice on same block or expose legacy replacement audition to audience. No native playback routing change.
Observer measures 5 fixed normalized Q1.3 BPF pairs per channel on dry/wet, 30ms exponential mean-square energy, no stereo cancellation, valid after 30ms of observed PCM, -120..+120 dBFS bounds; independent of detector and no effect on wet. Analysis lease renewed only via exact existing graph/slot/instance snapshot request. Lease expires after 0.5 seconds processed audio without renewal; no wall-time claim, no persistent toggle. Inactive path does not run measurement filters. SPSC snapshot is extended, serialized by CONTROL; no PCM crosses WebView. Audio uses fixed stack scratch and bounded operations; active observer adds 20 BPF ticks/stereo sample plus energy bookkeeping. CPU cost and WCET require measurement; no new buffering latency, no new graph, no lock/heap in the added processing loop by inspection. Existing processor bypass semantics unchanged.

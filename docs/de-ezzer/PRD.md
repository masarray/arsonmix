# de-Ezzer — product requirements (DS-00)
Owner name: de-Ezzer. Native ArSonMix built-in FX for live singing, speech, recording and streaming. Goal: meaningful reduction of excessive sibilance, preserving air, articulation, harmonics, body and stereo image. Not a noise reducer, source separator or fixed treble EQ. Beginner workflow: insert, Auto, Amount, listen, check real GR/Delta; advanced Sensitivity, Range, frequency and response only when supported. Voice/Singing/Allround are planned policies; Auto must not claim classification based on channel labels. Music protection and strong actual benefit must coexist. No forced Learn or cloud/ML requirement.
 
DS-01 baseline exposes only enabled, Amount, Sensitivity, Range and actual applied high-residual gain. Proposed default .5/.5/8 dB. Do not advertise unsupported modes/controls. Future editor: compact graphite/champagne amber, actual spectrum/reduction, Detect/Delta, preset and existing close/power icon semantics. Single approved /preview/ and one editor source. Mock only in clearly isolated harness.

Acceptance: meaningful 3–8 dB default on defined severe fixtures; stronger setting measurably stronger; protected body within 0.5 dB on controlled selective fixture. Real vocal corpus and blinded matched-benefit listening required before global-quality claim. Live: no added buffering if feasible, bounded callback, mono/stereo, 44.1–96 kHz. Product release requires actual native graph/FX Rack/ACK/state, Windows exact-SHA CI, installer and physical ASIO qualification. No product catalog admission at DS-01.

Research: https://pubmed.ncbi.nlm.nih.gov/11008825/ and https://pmc.ncbi.nlm.nih.gov/articles/PMC10540850/ document spectral/temporal and noise-like fricative evidence; https://www.softube.com/user-manuals/deesser describes detector and removed-signal auditions. No proprietary implementation copied.
 
DS-02 low-mid witness alone misses initial and isolated unvoiced bursts. Add explicit Voice mode only: second-order linear predictor error on complementary HF residual, smoothed energy of h[n-1], sum h[n]+h[n-2] and cross covariance; normalized residual = (E_sum-Cross^2/E_prev)/(E_prev+epsilon), clamped 0..4; single stationary sinusoid has near-zero error. Ramp authority .12.. .47 and HF power 1e-7..1e-6. Max baseline excess or bounded 12dB evidence with HF/body ratio >max(1,user threshold), same linked gain computer, no lookahead. Not a calibrated classifier, and sample-rate dependence remains. Auto defaults and DS-02 detector unchanged; mode change resets predictor histories. No source-role wiring or Singing mode.

Native offline tool de_ezzer_render uses same Core; mono/stereo PCM16/24/32 and IEEE float32 RIFF input, float32 output wet and dry-wet Delta, no extra sample delay, no gain normalization, rejects malformed/truncated inputs, unsupported formats, new output paths required. Tests PCM decode, exact float roundtrip, bit-identical partitions, wet+delta within 1e-7, active nonzero and zero-Amount exact zero delta. No actual native audition/editor. Phase residual is not isolated phoneme. File I/O entirely outside audio callback. In-memory 256MiB RIFF limit; no extensible/RF64 or compressed support; partial outputs may remain on failed write, and no concurrent-writer guarantee.

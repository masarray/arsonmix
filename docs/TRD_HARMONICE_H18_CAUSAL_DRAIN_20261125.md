## Design
Existing engine hard-stops the entire PSOLA call when completeEpochWindow fails, despite H14 proof that previously admitted grain taps remain safe. H18 separates new-epoch permission from rendering existing grains. During unsafe admission, skip all epoch searches and new grain admission, advance bounded target clock, render only validated existing windows until they expire, reset stale schedule once drained. Stereo lead and historic reference paths unchanged. No PCM buffer, FFT, allocation, latency or schema change.
## Validation

Native bass/high fixture traverses causal lookback, verifies actual losses and acquisitions, exact block/dry parity, gain and normalized maximum edge bound. Offline continuity exports H12–H18 matched WAV, H14–H18 role stems and per-role transition counts (H12 legacy seam not instrumented); actual temporary-directory file export/readback self-test. No human vocal or hardware proof. Keep H16 FAT running, no duplicate while active.

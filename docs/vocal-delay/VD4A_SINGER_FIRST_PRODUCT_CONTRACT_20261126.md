## VD4A implemented candidate
- Default Singer mode: Style, Time, Repeats, Echo Level, TAP/rhythm, ON/OFF; concise descriptions, compact panel and one-click Smart voicing. Expert opens the same controls plus stereo, duck amount/attack/release and HP/LP. Switching is presentation-only; no parameter submission, state revision or PCM change.
- Ten voiced presets, including new Studio Clean and Warm Vocal. They are parameter-based continuous delay voicings, NOT new tape/multitap algorithms. Preset selection recalls settings; subsequent level/time/repeat edits retain style identity based on expert voicing, reconstructed from saved state. Expert changes outside a named voicing display Custom.
- Smart voicing is explicit, deterministic, idempotent mapping from current time, feedback and level to five expert fields (HP, LP, duck depth, attack, release). More dense/long echo gets stronger cleanup and ducking. Existing realtime envelope acts on wet only. This is not adaptive microphone analysis; no automatic hidden rewrites, no changes to dry, level, timing, feedback, stereo or power. Expert controls remain editable. V2 state format unchanged; old V1 remains exact.
- Test mappings/ranges/roundtrip and actual JUCE mode switch, visibility, no revision, smart transaction and final delivery. Existing DSP no-heap, PCM and concurrency tests retained.

# VD9 — singer dynamic re-entry and reproducible audition
Baseline: VD8 c0a7c27e. Stage detector was relative to a peak reference that decays over 1.8 s. A quiet phrase after a loud one could remain under the reference threshold and fail to duck. Smart Stage now caps relative thresholds at .010/.035 amplitude (absolute floor retained); old non-stage detector unchanged. Tests at 8/44.1/48/96/192 kHz cover loud→silence→quiet return, 30 ms breath and real silence. Persistent loud background may still hold ducking: no voice isolation is claimed. Stage preset highlight becomes Custom if focus/tail policy manually changes; manual time/feedback/echo remain associated with the voicing.
## Reproducible audition
Build from repository root: `g++ -std=c++17 -O2 tools/vocal-delay/audition.cpp -o vd-audition` (or MSVC C++17). Run `vd-audition audition-output` for deterministic harmonic fixture or `vd-audition audition-output dry-voice.wav` for an actual mono/stereo PCM16 dry recording up to 60 s. Outputs 14 level-consistent stereo WAVs (dry, original Live Vocal, 12 Smart Stage), pre-quantization peak/wet/side RMS and clipping frame count, safe free-time fallback and 3 seconds tail. No normalization, no fake vocal, no simulated genre, no added runtime code. CI uploads exact source audition bundle. Listening is not equivalent to ASIO monitoring.
## Physical acceptance
Compare original Live Vocal and Smart Live with same microphone/input level, headphones then mono speaker, low and high voice, fast lyrics and breaths, loud-to-soft transition, pause and return, all genres, no operator; check rhythmic fallback with absent clock and valid source; audition stereo Ping Pong; change presets while singing; toggle wet power and rack bypass. Record interface, buffer, sample rate, CPU/xruns, preset, subjective clarity/sweetness/space/fun, and any audible tail or click. No automatic full FAT or approval from this synthetic suite. Preserve canonical integration until latest code passes and integration decision is made.

# REVERB-SIS | Inter, Lucide, meter alignment and proportion QA
Date: 2026-11-24. Owner-approved layout reference: HD-CART. Implementation: native JUCE in PR #887.

## Defects observed in authentic JUCE Windows image before this change
- Four meter LEDs drew from x390 and x617; left labels ended x387 (3px gap), right labels began x833 (20px from second meter's last LED ending x813). The combined group x313..922 was centred about x618, **58 px to the right of window centre x560**.
- Text label bounding boxes were 18px tall at y108/143, while dots were drawn at y113/148. Native glyph visual cap height appeared low and the optical baseline was not derived from dot centres.
- Bottom blue LCD from y355 to408 was 53px of a 430px window (12.3%). New LCD starts y374, is 34px (7.9%), a 35.8% height reduction; numeric slider readouts stay within the shorter LCD.
- Preset navigation used '<' / '>' font glyphs and generic font family. Combo native Label bounds were left to JUCE default, with independent caret location; text baseline could drift from icon.
- Decorative rule underneath REVERB-SIS (x47..286 at y104) adds noise with no function.

## Implemented single-source coordinate contract
A native `MeterLayout` table is reused by `paint()` and `drawMeters()`. One group from x250 to870, midpoint 560; left text box x250..336; left LEDs x348..544; right LEDs x562..758; right text box x770..870. Both text-to-dot gutters **12px**, computed with constexpr C++ static_assert. LED row y113 and148; text rects are derived from dot centres with an optical 2px cap-height adjustment. All meter values come from the real stereo PCM peaks, no synthetic animation in the production callback.

## Typography and icon provenance
- Inter family, checked-in **static Regular TTF** subset preserved byte-for-byte from [Bluesky Social `bskyogcard/src/assets/fonts/Inter-Regular.ttf`](https://github.com/bluesky-social/social-app/tree/main/bskyogcard/src/assets/fonts); Git blob `b7aaca8de1fe458399e17311d35d543a1fa2f984`. Static Regular was selected after a real Windows JUCE rendering demonstrated that JUCE 8.0.15 did not produce reliably legible strokes from the first variable-font asset. Original Inter authors retain copyright; Bluesky's font README explicitly documents the OFL-licensed subset. Source is under **SIL Open Font License 1.1**, license already bundled by the main app from `web/assets/fonts/OFL-LICENSE-Inter.txt`. A separate `ARMixReverbInterFont` JUCE binary-data target, in private namespace `ARMixReverbInter`, embeds the actual TTF into the production executable and matching Windows GUI test; users don't need to install the font, online resources aren't fetched at startup or build, and no installer asset folder is added.
- Draw Lucide's canonical **chevron-left/right** (viewBox 24, stroke-width 2, path `M15 18 L9 12 L15 6` / `M9 18 L15 12 L9 6`) directly as original-positioned JUCE vector paths with rounded strokes. Icon drawing uses the message thread, not the audio callback. Lucide Icons are ISC licensed: https://lucide.dev/license. The dropdown down-chevron uses the same shape language.
- `DialLook::positionComboBoxText` pins the JUCE internal child Label to full ComboBox height, with safe 9px left and 31px right insets. The dropdown caret is always drawn at 50% component height; preset and algorithm text use the same native Inter `Font` and line centre.

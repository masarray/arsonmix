# RTR-3B2 Global lifecycle and workload review

Research (26 Nov 2026): Steinberg [silence flags](https://steinbergmedia.github.io/vst3_dev_portal/pages/Tutorials/How%2Bto%2Buse%2Bthe%2Bsilence%2Bflags.html) are exchanged inside process; [processing FAQ](https://steinbergmedia.github.io/vst3_dev_portal/pages/FAQ/Processing.html) includes generators, parameter flushing, latency changes and RT constraints. JUCE [AudioProcessor](https://docs.juce.com/master/classjuce_1_1AudioProcessor.html) suspension is not proof of transparent wake. [Ableton monitoring](https://help.ableton.com/hc/en-us/articles/209072249-Reduced-Latency-When-Monitoring-FAQ) distinguishes compensation from intrinsic path latency and warns about retiming clicks. [Bitwig track/device deactivation](https://www.bitwig.com/userguide/latest/intro_to_tracks/) distinguishes deactivation from mute. Do not infer arbitrary VST idle safety from silence or tail hint; no host SDK patch asserted.

Implementation: vendor-neutral lifecycle dispatch uses only explicit exact-native/qualified-tail capability and bypass/fade/fault state. Existing processor contracts retained; no newly qualified arbitrary third-party sleep. Sampled bit-exact input/output silence (signed zeros only) is advisory. Native all-call timing remains; CH1 external graph adds sparse jittered workload observations and graph/physical-slot identity, resetting evidence on graph construction/device prepare, surviving MOVE. CH1 is sampled only and not a full-peak claim. First miss/max and 32-call batched publication avoid overload-triggered atomic writes every invocation. No new audio buffering. Diagnostics review list capped at 32, counts all candidates; 25% invocation budget is a review heuristic, 64 all-silent observations a candidate for investigation only, not a sleep authority. Latent bypass and latency faults get explicit review. No automatic bypass, reset, parameter change, or latency-removing deactivation. Existing GUI unchanged; recommendations in native status/report, not a new user-facing control.

Tests: existing 42k latent history and 4-rate budget fixture plus 96 lifecycle combinations, subnormal/nonfinite wake veto for diagnostic silence, review fences, overload batching and device-rate reset. Exact CI required. Full JUCE/Windows and physical workload effect not yet qualified. Preserve canonical #899 and cross-thread #837.

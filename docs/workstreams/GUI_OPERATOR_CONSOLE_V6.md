## Screen / interaction blueprint
- **Top rail:** compact device identity (actual backend/rate/buffer), audio health and *emergency OUTPUT MUTE*, show/session, Plugins, one advanced Setup/Patch. Remove redundant program/snapshot strips and mode navigation overload.
- **Main workspace:** MIXER default; horizontally scrollable Input/Group/FX Return/Monitor channel banks, full-height continuous physical LED meters and faders. A channel's upper region is stable IN | M/ST | ordered FX slots | SEND | OUT; lower PAN/MUTE/SOLO + meter + fader never jumps when FX/ROUTE/SENDS focus changes. Master pinned right. Bank arrows shift by viewport, not fake 10 channel count.
- **Direct IN:** click on **any** channel, native verified port list (hardware/virtual) and source format; e.g. Interface IN1→CH7, IN2→CH2 without opening Setup. If only one pin is actually enabled, say so precisely; never duplicate IN1 silently. Changing a source invokes one native intent and awaits ACK while existing accepted route remains.
- **Direct OUT:** choose existing MAIN, Group or legal physical/virtual output from native capability inventory. No fixed OBS path and no synthesized speaker route. Preview invalid alias/cycle and retain accepted audio if rejected.
- **FX:** all channel roles get actual VST3 slots, native catalog/file picker, per-slot toggle, drag reorder, click populated slot opens true vendor JUCE editor with ArSonMix-branded host window; unpatched channels may prepare FX but remain SILENT. No CH1-only lease. Group and FX Return controls only render after native capability confirms.
- **SEND:** simple + to an existing bus; PRE/POST and level; + New FX Return; Send-on-Faders with a clear header and instant return to previous main faders without altering source gain.
- **+ CHANNEL:** rightmost add-strip command presents MONO, STEREO, GROUP, FX RETURN, MONITOR where supported; no false CH11 until a native ChannelId has been ACKed.
- **One selected-channel inspector**, optional non-modal and overlay-only. Bulk crosspoint remains Advanced Patch. No duplicate routing settings page for common work.
- State text: `PENDING`, `ACCEPTED/LIVE`, `SILENT/NO SOURCE`, `MUTED`, `REJECTED/REQUIRES DEVICE`; LIVE comes from accepted graph epoch/revision AND truthful PCM/output gate. Browser mock fixtures must be unmistakably DEMO.

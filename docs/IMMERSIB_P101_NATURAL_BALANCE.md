## Design
Run actual exact Fixed PA core at 44.1/48k using low-peak multisine, settle one second, measure half-second synchronous Fourier coefficients, 15 bands 100–10000Hz, 7 factory scenes, mono/hard-L/antiphase; two Live Concert distance extremes held out. This is digital transfer not headphone/SPL or perceived loudness. Normalize at 400/560/800 Hz, median across scenes/source modes. Fit partial (-55%) broad shape error with regularization, five low-Q common RBJ bells at 194/560/1250/2800/6300 Hz; bounded aggregate response -3/+2.5dB, high band boost <=1.5dB. No inversion of nulls or new source-dependent EQ. Use common filter after all ear sums and before original linked limiter; same transfer at both ears preserves complex ratios for steady linear conditions. No guarantee perceptual externalization survives. At 0% MIX and ROOM OFF settled correction zero. Prepared once, no callback allocation/FFT or new delay. Existing Fixed PA voicings remain intact, including P80 actual capped extra relief (1.2dB, despite old caller requesting 3dB). Do not change this discrepancy in this experiment.
Calibration workflow produces exact-source generated header and CSV/JSON, then recompiles actual core and measures corrected response, requires improved median error, bounded measured transfer difference and interaural cue deviation, plus original PCM/Windows JUCE regressions. Windows downloads only same run calibration artifact; hashes included in package. CMake refuses missing table. Flag OFF by default. No public merge, no source-lock hash updates. A/B on same headset, same loudness and session; no manual user EQ initially. User listening remains decisive.

# P0 WASAPI capture click experiment — explicit muted A/B only

This milestone is an intentionally **OFF-by-default** candidate for real hardware FAT. It never automatically modifies capture PCM on startup, device reopen, Show recall or ASIO. After choosing a verified Windows Audio DIRECT capture/render pair, the operator must **MUTE OUTPUT** and enable **CAPTURE DE-CLICK: ON (BETA)** in SIGNAL CHECK. Then manually START AUDIO at low headphone volume. It disables itself at every audio device generation and does not apply to independent dual-clock mode or isolated tone/capture routes.

When ON, only candidate exact-zero-head discontinuities in stereo capture cause a bounded 64-frame prepared copy/repair (or invalid-sample sanitization); ordinary healthy blocks remain zero-copy. Candidate zero-head is NOT driver-proven xrun. An artificial zero prefix could be legitimate digital silence; compare against OFF under identical conditions and listen for coloration/artifacts. There is no proof of repaired or missing audio samples. No automatic output arm, buffer change, SRC, clock restart or additional DSP graph.

**FAT:** 0 FX, 48k/480 where supported, VB-Cable CABLE Output → MAONO wired out; A: OFF capture 5 user MARK CRACKLE windows, COPY FULL REPORT; B: MUTE → enable BETA → manual START AUDIO, capture 5 windows. Record raw capture candidate blocks/frames, repair blocks/frames, WASAPI capture discontinuity flags, sample rate/clock/endpoint/actual callback, post MAIN peak, audible change and any unintended tones. Repeat real MAONO ASIO/direct (BETA must be unavailable). Compare output-only isolated tone (BETA must be unavailable). A hardware clean run >=30 minutes is required before considering making the feature a recommendation; **do not automatically enable it in production**. P0 issue #15 remains open.

Benchmark for Console UI/navigation remains the official [Fender Studio Pro Console](https://fenderstudiopromanual.fender.com/en/Content/Mixing_Topics/The_Console.htm). This feature is a hidden opt-in engineering diagnostic, not an everyday Studio I/O step.
